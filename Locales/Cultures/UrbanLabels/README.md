# 城内地图标注

`Labels.csv` 为纯净地图的住宅街区、官署、市场、作坊、祭祀建筑、兵营、码头及宫殿提供文化名称。

- 格式为 `family,kind,cz,en,ch`，同一格内的备选名称用 `|` 分隔；名称中不使用逗号或换行，不使用 CSV 引号转义。
- `family` 可写具体文化 ID（例如 `Kosher`、`Slavonic`），也可写 `CityStyleSystem.Family` 返回的建筑家族（例如 `japan`、`nomad`）。查找顺序为本城文化、文化家族、`common`。
- `kind` 为 `ward`、`civic`、`market`、`industry`、`temple`、`barracks`、`docks`、`palace`。近代住宅、官署、市场、工业、军营、码头使用 `modern_` 前缀。工业图块 `industry_1`、`industry_2` 使用近代工业词库。
- `{city}` 替换成完整城名。近代住宅的楼号由程序追加，不写进词库。
- 文化按本城主流文化读取，缺少时采用所属国文化；与城市保存的建筑外观风格分开，文化同化无需改建就能更新标注。自定义文化可直接添加文化 ID 行；没有独有词库时沿用文化家族。
- 简中、英文、繁中各自取对应列；空列退回英文、简中，其他界面语言使用英文。

名称按城市、地块与建筑编号稳定选择，不写入存档。城名、主流文化、界面语言变化时会重新生成；不会覆盖村镇或厂区保存的自定义名称，也不会重新显示街道名。祭祀建筑的名称是文化风格标注，不改变游戏宗教。
