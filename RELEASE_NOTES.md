# 更新内容 (Update Features)

2026-11-17 · 0.4.7Beta10

服务器核心调快流速后，行军、决议、税收都跟着走，算不过来时显示实际流速。修复核心里各国长期不开战、都城丢了不补，天下不再几百年不变；定居文化乱世久了更容易出统一者。新增君主大政：迁都、设陪京与直隶、改制（内阁、分封、郡县、行省），要权威够高并过决议天平。修复渡海攻城占不了地，幕府可倒幕。

On the server core, marching, decisions and taxes now keep pace when the world is sped up, and the real speed is shown when the host cannot keep up. Fixed realms there never declaring war or replacing a lost capital, so the map no longer freezes for centuries; settled cultures unify more readily after long chaos. New ruler decrees: move the capital, name secondary capitals and a metropolitan province, reform the system — each needs high authority and must tip the decision scale. Fixed sea landings failing to take land; the shogunate can now be overthrown.
