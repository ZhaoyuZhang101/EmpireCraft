# 联机大厅发布说明

终端模式的联机大厅：玩家打开网页看到房间列表、点进去领一位君主；数据经大厅转给房主的电脑，世界在房主那边运行。

这个目录里有两套大厅，协议相同，任选其一：

| 文件 | 用在哪 |
|---|---|
| `worker.js` + `wrangler.toml` | Cloudflare（现在用的） |
| `lobby_server.py` | 自己的服务器（备用） |
| `lobby.html` | 大厅网页，两套共用 |

## 发布到 Cloudflare

要求：电脑上有 Node.js；域名 `cmhgamedev.dpdns.org` 在要用的 Cloudflare 账号里。

Node.js 版本低于 20 时（`node -v` 查看），下面命令里的 `wrangler` 都写成 `wrangler@3`，例如 `npx wrangler@3 deploy`。

1. 在这个目录（`Tools/TerminalLobby`）打开终端。在别的目录执行会报"Missing entry-point"，因为找不到配置文件；
   从模组根目录发布要写成 `npx wrangler deploy --config Tools/TerminalLobby/wrangler.toml`。
2. 登录（会打开浏览器让你授权，只需做一次）：

   ```bash
   npx wrangler login
   ```

3. 发布：

   ```bash
   npx wrangler deploy
   ```

   第一次发布会自动建好 `lobby.cmhgamedev.dpdns.org` 的解析和证书，证书签发要等一两分钟。

4. 浏览器打开 <https://lobby.cmhgamedev.dpdns.org/>，看到"联机大厅"和"眼下没有开着的房间"就是成了。

改了 `worker.js` 或 `lobby.html` 之后，重新执行第 3 步即可。

想换个子域名：改 `wrangler.toml` 里的 `pattern`，同时把模组里 `TerminalHost.DefaultLobby`（`Scripts/Terminal/TerminalHost.Lobby.cs`）改成一样的。

## 免费档的额度

- 每天 10 万次请求（世界协调时零点清零）。手机每 2 秒取一次数，大约够全体玩家每天合计 50 个小时。
- 超了以后当天的请求会失败。Cloudflare 后台的 Workers 用量页能看到每天用了多少。
- 不够用时升到付费档（每月 5 美元起），不用改任何代码。

## 游戏里怎么用

1. 模组设置里开启「终端模式」。
2. 打开终端窗口，点「接入联机大厅」。状态变成"已接入"后，左栏会显示大厅网址。
3. 房间默认凭配对码进入；点「改为公开」后，大厅里有空席位的人点了就能进。
4. 把大厅网址发给要来的人。

想先连到自己测试用的大厅：模组设置文件里的 `Terminal_Lobby_Url_Text` 填测试地址（如 `ws://127.0.0.1:8787`），留空就是用内置的正式地址。

## 国内线路：自己的服务器

大厅有两条线路，各是各的房间列表，房主在终端窗口里选接哪条：

| 线路 | 地址 | 跑的是 |
|---|---|---|
| 国际 | `https://lobby.cmhgamedev.dpdns.org` | Cloudflare 上的 `worker.js` |
| 国内 | `http://8.159.129.136:8765` | 阿里云服务器上的 `lobby_server.py` |

国内线路的服务器换了地址，要同时改两处：模组里 `TerminalHost.Lobbies`（`Scripts/Terminal/TerminalHost.Lobby.cs`），和 `lobby.html` 里的 `LINES`。

### 部署到服务器

服务器上有 Python 3.6 或更高版本即可（Alibaba Cloud Linux 3 自带），不用装别的。

1. **放行端口**：云厂商控制台 → 这台实例的安全组 → 入方向 → 添加一条：协议 TCP，端口 `8765`，来源 `0.0.0.0/0`。
2. **传文件**（在模组根目录执行，会问服务器的 root 密码）：

   ```bash
   scp -r Tools/TerminalLobby root@8.159.129.136:/opt/empirecraft-lobby
   ```

3. **安装并启动**（同样会问密码）：

   ```bash
   ssh root@8.159.129.136 "bash /opt/empirecraft-lobby/install.sh"
   ```

   看到"大厅已在 8765 端口运行"就是成了。它会装成开机自启的服务，掉了自己重启。

4. 浏览器打开 <http://8.159.129.136:8765/>，看到大厅页面即可。

以后更新：重做第 2、3 步（第 2 步目标目录已存在时，改用 `scp -r Tools/TerminalLobby/* root@8.159.129.136:/opt/empirecraft-lobby/`）。

服务器上常用的几条：

```bash
systemctl status empirecraft-lobby
```

```bash
journalctl -u empirecraft-lobby -n 50 --no-pager
```

房间钥匙记在 `/var/lib/empirecraft-lobby/lobby_keys.json`，别删。

### 要知道的

- 国内线路眼下是 IP 加端口、明文 http，配对码不加密。等域名备案下来再换成域名和 https。
- 国内服务器对外开网页按规定要备案；备案下来之前用 IP 加端口属于灰色地带。
