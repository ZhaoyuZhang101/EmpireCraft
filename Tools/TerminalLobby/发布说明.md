# 联机大厅发布说明

终端模式的联机大厅：玩家打开网页看到房间列表、点进去领一位君主；数据经大厅转给房主的电脑，世界在房主那边运行。

这个目录里有两套大厅，协议相同，任选其一：

| 文件 | 用在哪 |
|---|---|
| `worker.js` + `wrangler.toml` | Cloudflare（现在用的） |
| `lobby_server.py` | 自己的服务器（备用） |
| `lobby.html` | 大厅网页，两套共用 |

## 发布到 Cloudflare

要求：电脑上有 Node.js；域名 `cmhgamedev.dpdns.org` 在要用的 Cloudflare 账号里。

Node.js 版本低于 20 时（`node -v` 查看），下面命令里的 `wrangler` 都写成 `wrangler@3`，例如 `npx wrangler@3 deploy`。

1. 在这个目录打开终端。
2. 登录（会打开浏览器让你授权，只需做一次）：

   ```bash
   npx wrangler login
   ```

3. 发布：

   ```bash
   npx wrangler deploy
   ```

   第一次发布会自动建好 `lobby.cmhgamedev.dpdns.org` 的解析和证书，证书签发要等一两分钟。

4. 浏览器打开 <https://lobby.cmhgamedev.dpdns.org/>，看到"联机大厅"和"眼下没有开着的房间"就是成了。

改了 `worker.js` 或 `lobby.html` 之后，重新执行第 3 步即可。

想换个子域名：改 `wrangler.toml` 里的 `pattern`，同时把模组里 `TerminalHost.DefaultLobby`（`Scripts/Terminal/TerminalHost.Lobby.cs`）改成一样的。

## 免费档的额度

- 每天 10 万次请求（世界协调时零点清零）。手机每 2 秒取一次数，大约够全体玩家每天合计 50 个小时。
- 超了以后当天的请求会失败。Cloudflare 后台的 Workers 用量页能看到每天用了多少。
- 不够用时升到付费档（每月 5 美元起），不用改任何代码。

## 游戏里怎么用

1. 模组设置里开启「终端模式」。
2. 打开终端窗口，点「接入联机大厅」。状态变成"已接入"后，左栏会显示大厅网址。
3. 房间默认凭配对码进入；点「改为公开」后，大厅里有空席位的人点了就能进。
4. 把大厅网址发给要来的人。

想先连到自己测试用的大厅：模组设置文件里的 `Terminal_Lobby_Url_Text` 填测试地址（如 `ws://127.0.0.1:8787`），留空就是用内置的正式地址。

## 改用自己的服务器

服务器上有 Python 3.8 或更高版本即可，不用装别的：

```bash
python3 lobby_server.py --port 8765
```

然后在云厂商的安全组里放行这个端口，模组里把大厅地址填成 `服务器IP:8765`。它会在同目录写一个 `lobby_keys.json`，记着各房间的钥匙，别删。

## 本机联调
