# 联机大厅发布说明

终端模式的联机大厅：玩家打开网页看到房间列表、点进去领一位君主；数据经大厅转给房主的电脑，世界在房主那边运行。

**一键更新两条线路**：改了大厅的任何文件之后，双击模组根目录的 `update_lobby.bat`。它先把国际线路发布到 Cloudflare，再把国内线路传到阿里云并重启(会问一次服务器密码)，最后检查两边通不通。只更新一边：`update_lobby.bat cf` 或 `update_lobby.bat cn`；只检查不更新：`update_lobby.bat check`。

这个目录里有两套大厅，协议相同，两条线路各用一套：

| 文件 | 用在哪 |
|---|---|
| `worker.js` + `wrangler.toml` | Cloudflare（现在用的） |
| `lobby_server.py` | 自己的服务器（备用） |
| `lobby.html` | 大厅网页，两套共用 |

## 发布到 Cloudflare

要求：电脑上有 Node.js；原来的域名 `cmhgamedev.dpdns.org` 2026-11-28 被 Cloudflare 封了，国际线路眼下用 workers.dev 地址(`wrangler.toml` 里 `workers_dev = true`)；以后挂 `cmhai.tech` 要先把它加进同一个 Cloudflare 账号。国内线路的 `lobby.cmhai.tech` 解析要保持"仅 DNS"(灰云)，指向阿里云。

Node.js 版本低于 20 时（`node -v` 查看），下面命令里的 `wrangler` 都写成 `wrangler@3`，例如 `npx wrangler@3 deploy`。

1. 在这个目录（`Tools/TerminalLobby`）打开终端。在别的目录执行会报"Missing entry-point"，因为找不到配置文件；
   从模组根目录发布要写成 `npx wrangler deploy --config Tools/TerminalLobby/wrangler.toml`。
2. 登录（会打开浏览器让你授权，只需做一次）：

   ```bash
   npx wrangler login
   ```

3. 发布：

   ```bash
   npx wrangler deploy
   ```

   第一次发布后 `empirecraft-lobby.zhangzhaoyu101.workers.dev` 要等一两分钟才生效。

4. 浏览器打开 <https://empirecraft-lobby.zhangzhaoyu101.workers.dev/>，看到"联机大厅"和"眼下没有开着的房间"就是成了。

改了 `worker.js` 或 `lobby.html` 之后，重新执行第 3 步即可。

想换个子域名：改 `wrangler.toml` 里的 `pattern`，同时把模组里 `TerminalHost.DefaultLobby`（`Scripts/Terminal/TerminalHost.Lobby.cs`）改成一样的。

## 免费档的额度

- 每天 10 万次请求（世界协调时零点清零）。手机每 2 秒取一次数，大约够全体玩家每天合计 50 个小时。
- 超了以后当天的请求会失败。Cloudflare 后台的 Workers 用量页能看到每天用了多少。
- 不够用时升到付费档（每月 5 美元起），不用改任何代码。

## 游戏里怎么用

1. 模组设置里开启「终端模式」。
2. 打开终端窗口，点「接入联机大厅」。状态变成"已接入"后，左栏会显示大厅网址。
3. 房间默认凭配对码进入；点「改为公开」后，大厅里有空席位的人点了就能进。
4. 把大厅网址发给要来的人。

想先连到自己测试用的大厅：模组设置文件里的 `Terminal_Lobby_Url_Text` 填测试地址（如 `ws://127.0.0.1:8787`），留空就是用内置的正式地址。

## 国内线路：自己的服务器

大厅有两条线路，各是各的房间列表，房主在终端窗口里选接哪条：

| 线路 | 地址 | 跑的是 |
|---|---|---|
| 国际 | `https://empirecraft-lobby.zhangzhaoyu101.workers.dev` | Cloudflare 上的 `worker.js` |
| 国内 | `https://lobby.cmhai.tech` | Caddy 转发到阿里云上的 `lobby_server.py` |

国内域名已完成备案并启用 HTTPS。Caddy 监听 80/443，自动申请和续期证书，反向代理到 `127.0.0.1:8765`，同时转发房主的 WebSocket 连接。旧地址 `http://8.159.129.136:8765` 继续接入同一个大厅。

### 部署到服务器

服务器上有 Python 3.6 或更高版本即可（Alibaba Cloud Linux 3 自带），不用装别的。

1. **放行端口**：在云厂商控制台为该实例的安全组放行入方向 TCP 80、443 和 8765，来源 `0.0.0.0/0`。80/443 用于 HTTPS 和证书验证，8765 兼容旧版连接。
2. **传文件**（在模组根目录执行，会问服务器的 root 密码）：

   ```bash
   scp -r Tools/TerminalLobby root@8.159.129.136:/opt/empirecraft-lobby
   ```

3. **安装并启动**（同样会问密码）：

   ```bash
   ssh root@8.159.129.136 "bash /opt/empirecraft-lobby/install.sh"
   ```

   看到"大厅已在 8765 端口运行"就是成了。它会装成开机自启的服务，掉了自己重启。

4. 服务器的 Caddy 使用下面的配置并保持运行，浏览器打开 <https://lobby.cmhai.tech/> 验证大厅。

   ```caddyfile
   lobby.cmhai.tech {
       encode gzip
       reverse_proxy 127.0.0.1:8765
   }
   ```

   检查 `https://lobby.cmhai.tech/healthz` 应返回 `ok`。证书验证若因端口不通失败，放通后可运行 `systemctl restart caddy` 立即重试，并用 `journalctl -u caddy -n 30 --no-pager` 查看结果。

以后更新：重做第 2、3 步（第 2 步目标目录已存在时，改用 `scp -r Tools/TerminalLobby/* root@8.159.129.136:/opt/empirecraft-lobby/`）。

服务器上常用的几条：

```bash
systemctl status empirecraft-lobby
```

```bash
journalctl -u empirecraft-lobby -n 50 --no-pager
```

房间钥匙记在 `/var/lib/empirecraft-lobby/lobby_keys.json`，别删。

### 要知道的

- 新版模组的国内线路使用 `wss://lobby.cmhai.tech`，手机房间地址使用同域名的 HTTPS。
- 大厅页脚显示备案号并链接到备案系统。
