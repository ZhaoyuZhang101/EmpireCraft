# 终端立绘与衣冠

立绘使用正脸和正面站姿，目标为 6.5～7 头身。青罗鹤补服是头、发式和帽身相对身体的比例参照。男版双臂自然下垂、双脚略分，女版双手叠在腰前、双脚靠拢。脸型和发式可以有差异，部件都按同一组人体锚点绘制。

## 画布

- 逻辑画布为 88×136，中轴是 x=44。高清图格为 352×544，按四倍坐标共用下表的锚点。发髻和冠顶留在颅顶以上的预留区。
- 颅顶到下巴约 17～18 格。脸宽包含耳缘，为 11.75～13.25 格（高清图 47～53 像素）。短发贴着这条颅顶线绘制，鬓发和发髻沿对应部位加体积。长发在肩前和肩后延伸，发尾宽度不作为头围。
- 帽身按发顶和两鬓的实际轮廓贴合。普通帽身宽约 14～19 格，帽檐落在额上约 y=20～21。冕板、乌纱帽横翅、缨饰和垂巾按各自形制延伸，量帽身时从这些装饰内侧取宽。
- 乌纱翼善冠采用朱元璋画像中的素黑冠面和后部短折角。[国立故宫博物院《南薰殿帝后像》](https://theme.npm.edu.tw/exh110/FacetsofAuthority/ch/page-5.html)
- 画完整的衣身、手和鞋。领边画在衣着层，脸层只画下巴和伸入领口的颈部。检查换装后颈部能与不同领口重叠，冠帽和发式留出脸部开口。添加一件男女通用的服饰时，分别画两种站姿，保持同一颈口和脚底线。
- 肩部从颈根向袖根展开，袖根沿肩面自然下垂。验收时在全身合成图检查下巴、领口和肩部是否连贯。打包时检查衣身与颈根重叠。敞领保留锁骨和胸口的露肤，厚袖、甲片和披风按各自剪裁画出肩部轮廓。
- 固定光线从左上来。沿用深色描边、成块的像素明暗、衣褶和纹样。

现用男女版的肩、腰、胯和站姿标点固定，在 `portrait_templates/index.json` 保存高清坐标。衣装沿模板绘制或调整。肩点标关节位置，宽袖的外边可以超过该点。长袍遮住膝和胯时，成图叠线只能核对可见轮廓，隐藏关节需以制图标点为准。

## 图层与图集

图层顺序为后发、底身、脸、衣着、面纹、胡须、前发、冠帽。完整服饰已包含姿势所需的手和鞋，底身在缺少服饰时显示。衣领叠在脖子前。长发分前后层，冠帽可在 `HAT_CLIP` 指定压住帽檐以上的前发，或用 `all` 同时收起前后发。

`portrait_art.png` 每行十格，`portrait_art.json` 的序号从左上角的零开始。图格名示例为 `body:ming:m`、`body:ming:f`、`hat:yishan`、`hair:taregami` 和 `back:taregami`。Alpha 0 为空白，255 为普通像素，254 标记可换肤色的脸、颈和手，253 标记瞳孔。页面合成时保留原画的明暗，并将这些像素换成角色的肤色、瞳色。

终端按需载入 `Terminal/portraits-hd.json` 中标准图格对应的无损 WebP 分片，分片内按从左到右、从上到下的顺序排列。高清立绘和内嵌小图集都按部件 ID 取图。换衣时，脸、发式和冠帽沿用原部件的图格。`profiles` 保留同一张原稿切出的样张部件供美术参考。

## 加入衣冠

### 服饰模板和手动对位

双击同目录的 `portrait_alignment.cmd`，或运行 `python Tools/IconForge/portrait_alignment.py`。

- 在「新服装套模板」选人体模板，载入透明 PNG。载入原稿的标点 JSON 后，默认按下巴、颈根、肩、腰、胯、膝和脚底分段调整衣身。没有标点的旧图先在原画上标一次。被长袍遮住的点按衣服下的人体位置标。关掉自动对齐可手动调整整图尺寸和位置。
- 全部标点都落在模板目标的 2 个高清像素以内才可导出。交付时将透明服装 PNG 和同名标点 JSON 一起保存。另可导出带参考线和标点的核对图。外部绘图软件导出的服装也可运行 `python Tools/IconForge/portrait_templates.py --check 服装.png 标点.json` 验证。模板 PNG 和坐标表在 `portrait_templates/`。
- 新登记到现用终端图集的衣身采用对应的「终端现用」模板，并把导出的标点 JSON 存为 `portrait_templates/garments/装备ID-m.json` 或 `装备ID-f.json`。终端打包会校验新增图层的标点。现有衣装可逐件补录，同名标点一旦提供也会校验。
- 在「终端立绘对位」选择一套衣装和版型，再选脸、发或帽。可以拖动单层或头部整组。衣身使用颈根标点对齐，须同时通过颈根 `(44, 37)` 和脚底 `y=134` 检查。只有「保存到本地终端」会写入 `portrait_alignment.json` 并应用到本地网页。
- 幼年、学龄、少年、青年和成年矮、中、高档是绘制服装用的人体参考，各有男女版。身高数值用于按同一画布比例制作体型，年龄与头身是美术设计参考。终端现用男女版兼容当前游戏的成人图层。 [不同年龄的人体绘图比例参考](https://dl.tufts.edu/downloads/ks65hq479?filename=p55483313.pdf)

### 图集打包

1. 将服饰画在同一套锚点上，按性别分别对齐。在源图集追加小图格，并在 `portrait_art.json` 登记序号。用高清原画更新分片与 `portraits-hd.json`。分片文件名中的 12 位十六进制数为文件 SHA-256 的前 12 位。
2. 在 `portrait_forge.py` 登记稳定的装备 ID、名称、文化、性别、类别、时期和默认冠帽。已有装备的 ID 用于终端衣柜。
3. 运行下列命令重新打包，然后在终端衣冠页检查完整立绘和小头像。

   ```sh
   python Tools/IconForge/portrait_forge.py
   python Tools/IconForge/terminal_portraits.py
   ```

打包会生成 `Terminal/portraits.png`、`portrait_parts.json` 和供服务端计价的 `Terminal/wardrobe.json`，并把小图集与高清分片索引嵌入 `Terminal/index.html`。打包脚本会核对小图集的 Alpha 标记，并检查页面和各高清分片是否符合终端中继的大小上限。
