# 宗教传播按史实重做方案（2026-10-27）

## 起因

用户截图：全图只剩两个宗教。基督教从西欧铺到北非、中东、印度西部；蒙古萨满教(腾格里)铺满了中国、日本、东南亚、印度东部。用户的评语是"太离谱了""要符合历史实际的发展"。

## 根因（BackgroundReligionSystem）

1. **扩散远快于创教。**
   - 无教之城每年最多有 15% 的几率跟邻城改信(AdoptChance)，不论邻城是不是同一个文明。哪怕只有一丝外来势能，年年掷骰，最终也会改信。
   - 创教要求本城、所在国都没有宗教，每城每年 0.8% 的几率(FoundChance)，全图还有 5 年冷却。
   - 所以第一个立起来的宗教会先把周边铺满。
2. **被铺满的文明再也立不起本土宗教。** 城一旦有了宗教就不能创教，华夏、乌玛、印度一直轮不到。
3. **民族宗教也跨文明外传。** 腾格里的传教力只有 0.3，但打折并不能阻止扩散，只是慢一点。
4. **征服者不从俗。** 游牧国家的国教势能照样推到治下的农耕城。历史上恰好相反：伊儿汗国改宗伊斯兰，元朝崇佛。

## 方案

### 一、先有民间信仰，各文明到了时代再出本土大教

- 开局没有宗教的城算作"民间信仰"，不立宗教对象，与现在一样。
- 每个天下标识(文化配置里的 tianxia)对应一个本土大教，类型照现有 ReligionFaith：

  | 天下标识 | 本土大教 |
  |---|---|
  | Roma | 教会 |
  | Umma | 伊斯兰 |
  | India | 法教 |
  | Huaxia | 三教 |
  | Tenka | 神道 |
  | Steppe | 腾格里 |
  | Kosher | 犹太 |
  | 其余 | 民间宗教 |

- **出现时机：**
  - 天下里有文化研究出「礼仪祭祀」(ritual_rites，二档)后，在本天下人口最多的城立教，这座城就是圣地。
  - 教会、伊斯兰这种一神普世教在史上出现得晚，要再研究出「冶铁」(ironworking，四档)。
- **创教不再要求本城无教。** 本天下还没有本土大教时，即便核心城奉着外来宗教，也照样立教。
- **立教后有本土优势：** 本天下的城改奉它，沿用现有的正教势能加倍。

### 二、跨文明传播加阻力

- 邻城、国教的势能，凡是跨了天下(城的文化天下标识 ≠ 宗教的天下)就打折：
  - 普世宗教(教会、伊斯兰、法教)：× 0.25
  - 民族宗教(腾格里、神道、三教、犹太、民间)：× 0.05，几乎不向外传
- 本天下已有本土大教时，外来宗教在本天下改信、改宗的几率再减半。

### 三、跨文明改宗主要靠君主和征服

- **君主皈依**沿用现有的 ReligionConversionSystem：普世宗教靠君主皈依后国教势能推行四十年。
- **入主者从俗(新增)：**
  - 条件：君主奉的是民族宗教，治下过半人口奉另一个天下的本土大教。
  - 结果：君主每年 10% 的几率改奉治下的大教，国教随之改。
  - 对应蒙古在伊朗皈依伊斯兰、元崇佛、清从俗。

### 四、已经铺满的世界(本土回流)

- 本天下的城奉着**外来的民族宗教**(华夏城奉腾格里)：每年 8% 回归本天下的本土大教。本土大教还没立的，先按第一条立。
- 奉着**外来的普世宗教**(乌玛城奉基督教)：不强制回流，但本土大教的正教势能加倍照算，会长期拉锯。

### 五、能看到的

- `[宗教诊断]` 日志加三项计数：跨天下改信、本土回流、入主从俗。
- 宗教窗口概况页刚加的"奉本教的天下"卡片能看到各天下的信众占比。

## 待定(问答)

1. 本土大教的出现时机：二档礼仪祭祀、一神教再加四档冶铁(推荐)；开局即有；或照旧随机，只是不再被外教挡。
2. 已铺满的世界：只回流外来的民族宗教(推荐)；外来普世宗教也回流；或不回流。
3. 跨文明阻力的强度：普世 ×0.25、民族 ×0.05(推荐)；一律 ×0.1；或普世宗教不打折。
