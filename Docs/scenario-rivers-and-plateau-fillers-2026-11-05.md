# 预设河流被地表遮盖与高原补空碎国

用户反馈预设剧本看不到长江、黄河，西藏高原散布零碎异色小国。

## 河流

`rivers.bytes` 数据和生成调用均存在。`EarthTerrain.Wet` 原来调用 `setTileType("shallow_waters")`，该原版 API 只替换底层，不清除 `top_type`。旧草地、树林、雪丘仍覆盖浅水，`WorldTile.Type` 优先返回表层，画面和部分判水逻辑因而仍视作陆地。已只读检查本机最新临高自动存档：12,405 格浅水残留陆地表层，全部落在原河流栅格内，其中高原段也有浅水覆盖雪丘的错误组合。

- 画河改用 `setTileTypes("shallow_waters", null)`，保留原渡口和宽度规则。
- 基础地形铺设也统一显式传入表层；无表层的海湖会清掉旧表层。
- 地球剧本首次划无人区前，沿原河流栅格修复仍为浅水底层的错误陆地表层。只清理现存水道，不把玩家已填成陆地的河段重新挖开；保留道路、城墙、农田，不修改河流栅格以外的格子。原版临时结冰标记保持不变。
- 未改写用户存档文件。更新后重启模组、读入地球剧本存档，在首次划区时应用修复；导入的非地球地图不运行此地球河道修复。

这次修复显示与地块状态，不重绘各时代的历史改道，也不改变现有河流折线来源。

## 高原随机小国

原补空算法只验证单区块能建城；山地、冻原和河湖包围的小块宜居地也会建立随机国家。高原周围又按剧本指定的无人区归属着色，便形成异色小块。

- 增加连通宜居腹地检查：至少8个区块，经真实路口相通，不穿越山脊、边墙、水面或新判定的无人区。
- 只限制随机补空；史实城市、玩家明确指定的部落照旧保留。足够大的独立岛屿和河谷仍可补城。
- 建城寻址也使用筛选结果，避免选点合格、随后寻址却搬到旁边的小碎片。
- 新开剧本生效；不在旧档中删除已经存在的城市、国家或战争结果。未据此将藏区重新统一，也未重绘1628年各地方政权的历史边界。
