# 战争与外交透明化方案(11-09，未开工)

## 要解决什么

玩家原话(11-08~11-09 群里)：

- 「我这边显示战争胜利」「但没有吞并敌国」「割地都没有」「就是赔款」
- 「现在帝盒的战争系统对玩家而言已经完全变成混沌系统了」
- 「手动开战开不了」「想要和平和不成」
- 「目前其实还是以战争理由为准」
- 「春秋的战争谈判系统限定开战几年后才能谈判和平，这个我觉得挺好」「有个限位防止 bug 大量发生」
- 「我昨晚上已经观察到好几次，天下统一战争一开打就收岁币强制和平，然后代码限制接着开打，又接着白和了」
- 「如果以谈判机制为准的话」「就要做分数了」「所以很多帝国扩张都是靠的臣服」

核对代码后的判断：**不透明的不是外交，是战争**。

- 外交面板这一层其实已经够透明：`DiplomacyLedger.OpinionParts` 把好感逐条列出，`DiplomacyWindow.DrawOpinion` 双向各画一张卡；每个操作不可用时 `DiplomacyActions.Check` 返回具体原因键，面板用灰字写在那一行(停战年限、够不着、同盟、同帝国、分治的兄弟之国、扶立之君……十几条各有文案)。
- 战争这一层一样都没有。战争目标在 `WarGoalSystem` 开战那一刻按兵力比、接不接壤、对方城数算出来(吞并要兵力两倍且对方不超三城或不到我方一半；割地要接壤且兵力够；其余赔款)，**定下就不再重算**。开战时兵力一点三倍，目标就是赔款；之后打了十年把对方打剩两座城，结算还是赔款。玩家既看不到「为什么是赔款」，也没有任何办法把它变成吞并——「混沌」就是从这来的。

### 最典型的一例：统一战争的白和循环

华章观察到的这一条把前面几个毛病串成了一条链，值得单列：

1. 天下统一战争开打，开战那一刻双方兵力相当、或攻方跨海够不着，`WarGoalSystem` 把目标定成**赔款**；
2. 赔款是立刻就能兑现的条件，于是一开打就收岁币、当场议和——**白和**；
3. 停战年限到了(或者统一战争本来就豁免停战年限)，同一对国家接着开打；
4. 目标还是开战那一刻算的赔款，于是又白和。

一场本该打到灭国的统一战争，变成了每隔几年收一次岁币。后果就是急了说的「**很多帝国扩张都是靠的臣服**」——仗打不出地来，版图只能靠臣服长。

这条链上每一环都对应下面的一项改动：目标定死 → 每年重算；没有最短战期 → 加硬下限；没有贡献度 → 做分数(急了也独立得出了同一结论：「就要做分数了」)；玩家看不到这一切 → 战争卡。

## 三个来源各取什么

**全面战争：三国 —— 双边这一层。** 它的标杆之处是三件事：每一项都明码标价(钱、地、附庸、技术、通行权各折成数值，交易栏实时算总价与对方满意度)、态度全明细(每条加减项可见，另有独立于好感的「信任」轴)、AI 会还价(不是同意/拒绝二选一，而是「再加这些我就答应」)。帝盒**已有**态度明细与拒绝理由，**缺**估价与还价。

**帝盒现有框架 —— 不另起炉灶。** 新东西一律挂在现成的四个入口上：`DiplomacyActions` 的 check/run 分离形制、`DiplomacyLedger` 的关系账、`WarGate` 的统一开战闸、`WarGoalSystem` 的战争目标。界面沿用「卷册」宽窗(见 plan-diplomacy-window.md)。

**钢铁雄心 —— 国际这一层。** 取它的阵营 + 参战方 + 战争贡献度 + 和会按贡献分配战果。帝盒已有阵营的雏形(同盟、帝国、反帝同盟、`WorldWarSystem.PoliticalBloc`)，也已有「世界紧张度」的等价物(`TianxiaSystem` 的治世/动荡/乱世)，**缺的是贡献度与和会**——现在多方参战打赢了，战果怎么分没有任何规则。

## 一、为什么打仗

**开战理由(casus belli)升为一等公民。** 现在开战动机散在各系统里：法理宣称(`DeJureAgenda`)、收复、宗教(`ReligiousTension`)、朝贡背离、称帝不服(`EmpireFormationService` 的怨恨)、统一天下(`UnificationDrive`)、开国雄主一统(`WarlordUnificationSystem.FounderDrive`)、劫掠(`NomadRaidSystem`)。统一登记在战争上，一场战争只有一个理由，理由决定**目标的上限**(例如劫掠永远不能升到吞并)。

**战争目标每年重算。** 这条最对症，也最省事——算式现成，只是现在只跑一次。改成每年、或占领比例变化时重算：兵力拉开到两倍、对方只剩三城，目标自动从赔款升到割地、再升到吞并。重算时受理由的上限约束。

**战争卡把算式摊开。** 照全战三国明码标价的思路，显示：谁因为什么开的战、当前目标、为什么是它(「兵力一点三倍 < 吞并所需两倍；对方七城 > 三城且超过你一半」)、以及**还差什么才能升级目标**。玩家知道差什么，才谈得上「系统」。

**地图上点宣战被拒要弹原因。** `CanDeclare` 的原因键全都有，只是面板之外的操作静默失败。用 `WorldTip` 弹一行即可，改动量极小但感受差别很大。

## 二、为什么议和

**战争贡献度。** 新增 `WarScore`，挂在 `WarExtraData` 上，每个参战方按攻破城池(主)、歼敌、出兵时长记分。这是现在完全没有的东西。

**和会。** 战争结束时按贡献度分配战果：哪几座城割给谁、谁收附庸、谁拿赔款。出力少的盟友拿不到地——现在是盟友蹭战果，没有规则。和会的结算表 AI 与界面共用同一份，不许两套说法。

**最短战期与停战保护期(采纳群里「春秋」的做法)。** 双向都要：开战不满 N 年不得议和；议和之后 M 年内同一方不得再宣战。后半条尤其重要——现在强制停战之后 AI 可以立刻重新宣战，开国雄主的统一战争在注释里就明确写着「不受战争年限强制停战」，这正是「想要和平和不成」的来源。华章说「有个限位防止 bug 大量发生」也对，这种硬边界能挡掉一大片状态竞争。

## 三、玩家的裁定权

战争卡上，上帝视角可以：

- 改战争目标(在开战理由允许的上限内)；
- 强制开/关和会，在和会里**手动分配**战果；
- 否决某一方入场，或强行把某一方拉入战争；
- 强制停战并指定保护期年限。

三条约定：

1. 全部走 `MembershipCooldown.ByGod`，不受新加的外交世界法则(`DiplomacyLaws`)限制——与现有约定一致。
2. 每一项旁边显示「AI 原本会怎么判」，改了之后记一条「神力裁定」的史册，方便回溯。
3. 最短战期、保护期这些硬限制对玩家不生效，只约束 AI。

## 四、透明度的三层

1. **列表层**：每个操作旁写明能不能做、为什么。**已有**。
2. **过程层**：战争卡——为什么打、打到哪一步、还差什么。**要做**。
3. **结算层**：和会——谁出了多少力、分到什么、依据是什么。**要做**。

## 数据层

- 新增 `CasusBelli` 枚举与登记，一场战争一个理由，理由定目标上限。
- 新增 `WarScore` 贡献度，挂 `WarExtraData`。
- 和会用一张结算表，玩家可改，AI 读同一张。
- 新操作一律沿用 `DiplomacyActions` 的 check/run 形制，不可用时返回原因键。

## 分期

1. 开战理由显式化 + 战争目标每年重算 + 战争卡 + 宣战被拒弹原因。(对症最快，不碰平衡)
2. 贡献度 + 和会。
3. 最短战期与停战保护期。
4. 还价：战争卡上显示「现在停战对方肯给什么」「再占几座城能换到割地」。

## 议和台(11-10 问答定，示意图 Tasks/ui-mockups/peace-table.png 待定稿)

用户 11-10 看战争窗口截图："要不要照着全战三国的逻辑做""玩家可以添加筹码""添加双方的""也可以取消""感觉目前的还是只能给看和就改个目标""这样子也不美观"。

已定：

- **单独一页「议和」**，左栏放在概况与战线之间。两栏「甲 出 / 乙 出」，每项一行带折价与撤销，栏底「添加」按类列出能出的条件(城池逐座、赔款分档、岁供、称臣、扶立、通商、改宗)，出不了的灰着写原因。
- **签约**：两国意愿都 ≥ 0 才能点「签约」；另有「强令签约」，不要代价，记一条神力裁定史册。还有「照目标开价」「撮合」「清空」。
- **AI 也按台子议和**：满最短战期后每年议一次，主攻方照目标开价，再撮合到两国都肯就签，条款逐项写进战报。攻下主城池照旧即胜、按目标结算，不进台子。
- **概况页收紧**：「为什么是这个目标」收成四格门槛(兵力对比、割地、吞并·臣服、城数)，改目标的说明挪进提示框，筹码与折价挪到议和页。界面文字不写「你」，一律写国名。

算账(示意图上的口径，进游戏再调)：

- 意愿 = 所得 − 所失 + 战局 + 疲敝；战局 = 对方筹码 − 己方筹码(赢家要拿回本钱，输家得让出这么多)。
- 筹码 = 攻下的城 + 占着的城 × 占比 + 兵力优势 + 年数。**兵力优势要封顶**(示意按 4 倍为止)：现在 `PeaceTermRules.Leverage` 按 (倍数 − 1) × 120 不封顶，截图里 63 倍就折出 7,440，远超城价。
- 割都城或过半城池守方死战(沿用 `Excessive`)。
- 撮合：先撤贵的、再补便宜的，不动主城池。
