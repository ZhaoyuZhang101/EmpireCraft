# 军牌前后抽搐修复（群友 2026-11-10「军牌为啥会前后抽搐」）

## 根因
地图上的军团牌（`CorpsMapRenderer`）在军团「带主将、且主将离军团 ≤2 格」时：
1. 直接取主将的**每帧动画实时坐标** `general.current_position` 当目标（主将在格子里走动、待机小晃都会带着牌子动）；
2. 这一支**不经 Glide 平滑**，每帧硬贴上去；
3. `follows` 判定是「≤2 格」一刀切，主将正好在 2 格边界时逐帧翻 true/false，目标点在「主将位置」和「军团自身 DrawPosition」间来回弹。

## 改动（均在 Scripts/UI/Components/CorpsMapRenderer.cs，不碰存档）
- 跟随目标改用**主将所在格子的中心** `current_tile.posV3`，不再取实时 `current_position`——主将在格内怎么走/晃，牌子都不动；
- 跟随这一支也走 `Glide` 平滑（只有行军中的 `marching`，因 DrawPosition 本就逐帧匀速插值，才直接贴）；
- `follows` 加滞回：≤2 格开始跟随，拉开到 >3 格才松开，消掉边界逐帧翻转；状态表在切换/读档世界时清空。

## 游戏内测试
- [ ] 开着「显示军团/驻军」。找一支**带主将、驻扎不动**的军团：牌子应稳定不抖（以前主将一走动就前后抽搐）。
- [ ] 一支**行军中**的军团：牌子沿路匀速前进，不一顿一顿、不前后跳。
- [ ] 主将与军团拉开到约 2~3 格（主将掉队/绕路）：牌子不再在主将与军团间高频来回弹；拉开超过 3 格才切回画在军团本体，且是平滑滑过去。
- [ ] 点军团信息里的「定位」跳转：仍能正确定位到牌子实际位置。
- [ ] 海军/运兵船的牌子照旧正常（未改动）。
- [ ] 读一个旧存档：军团牌显示正常，无报错。
