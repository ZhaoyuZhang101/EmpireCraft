# 预设剧本行政辖境与澳宋立宪修正（2026-11-01）

## 行政辖境

用户澄清后，历史合理性调整收回到剧本默认地块数据层：明确的历史范围直接指定开局辖地及对应无人区归属，
未配置范围的地方沿用原有治所推算、地形代价、扩张预算和无人区距离规则。不再通过统一重分区、调整噪声或自动整理毛刺塑造历史轮廓。

平滑显示恢复 10 月 30 日偏移改动前的取样：原位 3×3 B 样条与单层低频噪声，移除三层坐标扭曲和新增的细碎起伏。
保留无人区地形掩膜、国家/法理填色、高亮和归属保存修正。

最小地图沿用原有城市筛选算法；七个内置剧本通过 `ranks` 默认数据为 37 座原本会被过滤的治所配置可见级别。
仍须满足地图范围与建城条件，不凭空创造城市。维护脚本为 `Tools/WorldMap/administrative_defaults_source.py`，
`--check` 可只读检查行政区是否缺少默认可见的治所。治所锚点本身不等于测绘边界。

无人区的法理和承载城市一起保存。州府锚点优先于连通检查找到的邻城；新增城市不会抢走剧本里仍有效的辖境。
原承载城市消失时，优先在原法理内寻找替代城市；法理消失后再修补归属。永久中立、手绘法理仍沿用原规则。

剧本设好的城市—行政区—法理—帝国关系也会保存。年度按法理划界不再推翻仍有效的历史安排，
AI 不会每五年自动把历史道、省重做成通用法理分区。玩家仍可明确发动行政区重组；实际征服、改隶、
法理改换、政体转型或帝国结构改变后，旧关系不再阻挡新的安排。法理兼属的上限、继承和兼属关系均未改动。

旧存档不会被强制恢复为开局版图：缺失的承载城市和行政关系按当前存档补齐，以免抹掉已经发生的战争、改隶。
新增历史默认地块在重新生成剧本时生效；旧档获得恢复原有平滑显示、保存归属、减少继续漂移的修正。

## 历史边界面数据

`WorldMaps/administrative_boundaries.json` 当前包含公元 117 年罗马剧本的 35 个行政范围（含意大利直辖区，
上下默西亚、上下潘诺尼亚按本剧本的合并层级组合）。数据来自 Harvard DARMC 的
[Boundaries: Provinces, ca. 117 CE](https://services1.arcgis.com/qN3V93cYGMKQCOxL/arcgis/rest/services/DARMC_Roman_World/FeatureServer/14)。
原图贡献者为 Matthew Polk，依据 Richard J. A. Talbert 主编的 *Barrington Atlas of the Greek and Roman World*（2000）。

坐标按 WGS84 经纬度取出，查询时以 0.04 度简化；保留岛屿、孔洞和来源年份。范围是历史近似，不是现代测绘边界。
数据适用的剧本编号和年份必须同时匹配，绝不直接套给 230 年或其他时代。原图中与剧本层级无法直接对应的合并区域未强行拆造。

数据按 [DARMC 数据使用说明](https://darmc.harvard.edu/data-availability)采用
[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)；本文件中的出处、数据文件里的 attribution、license 与
source_sha256 一并保留。此许可适用于该衍生边界数据，不改变模组其余代码与资源的许可。

其余时代目前仍依据各自治所和地形推算，并未宣称已补齐所有国家、所有年代的精确历史省界。
后续面数据可直接加入同一文件，或在自定剧本的 `polities[].boundary`（直辖区）、`divisions[].boundary`（行政区）中提供。
坐标采用标准 MultiPolygon 层级：多面 → 各面的环 → 各环的 `[经度, 纬度]` 点；每个面第一环是外界，其后为孔洞，环首尾闭合。
已有城心、玩家在剧本编辑器手绘的辖地仍有优先权。

生成与检查：

```powershell
python -X utf8 Tools/WorldMap/administrative_boundaries_source.py .
python -X utf8 Tools/WorldMap/check_administrative_boundaries.py .
python -X utf8 Tools/WorldMap/check_scenario.py . WorldMaps/eras/lingao.json
```

## 澳宋《共同纲领》

年度核对、制宪会议和条款同步共用同一个国体判断，穿越政体不依赖普通共和国标记。
已生效的《共同纲领》沿用原对象和编号；旧版本遗留的通用宪法名就地改为《共同纲领》，不另记一次颁布。
起草和条款推导成功后才提交文书及编号，失败重试不会累积空的颁宪次数。实际国体改变时仍依法另立新宪。

旧存档已有的宪法计数和历史记录保留，避免删除合法历史事件。

## 验证与实际限制

- 生产代码专项检查覆盖原有分区口径、边墙、历史默认范围的岛屿与孔洞。
- 显示检查覆盖城市/国家/帝国轮廓一致性、暂停时刷新、颜色与占领变化；原位采样另与偏移改动前的算法对照。
- 无人区检查覆盖锚点优先、保存/读取、旧档迁移、新增城市、原治所消失、原法理消失、征服与手动改隶后的让位。
- 行政区重组检查覆盖自动提议与手动提议的区别，以及原有权限、分帧、迁都、领土与暂停/恢复规则。
- 宪法检查覆盖 501 年/6012 次更新、旧档累计计数、旧名称迁移、一次性纠正错误国体、起草失败重试和真实国体变化。
- 七个预设剧本均通过数据校验。恢复原有分区规则后，已重新检查生产采样函数和分区逻辑；早期方案生成的离线预览尚未全部重新生成，不能作为当前版本的视觉验证。

离线预览由 `Tools/WorldMap/preview_administration.py` 生成，城市所属政权采用现有 `check_eras.py` 的近似距离分配，
边墙采用剧本折线，未替代游戏里的最终沿山脊筑墙。因此它验证分区算法与地形覆盖，不是游戏截图，也不等于实际游戏长时运行验证。
