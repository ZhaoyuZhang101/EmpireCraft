# 无人区与预设版图完善

按用户“参考CK3，包括无人区设定，分析后开始完善”的要求落地。本轮保留原平滑显示、地图单位分区、法理兼属和上限逻辑。
改动集中在中立状态的粒度、预设明确归属的数据接口、保存读取和编辑器一致性；没有将CK3地图或素材直接导入项目。

## 先更正一项调查结论

国家级 `wilderness` 确实先解析为首都法理，但完整挂接链中的 `WildernessSystem.HistoricalTitle` **已经寻找同政权的当地城市**。
上一轮将其简化成“全部最终挂到首都”不准确。本次没有重复改写那套分配算法，而是补充明确地区的优先级和默认数据。

## 中立只作用于命中的地块

- 剧本笔刷的 `n` 原先会把命中的整片连通无人区设为中立，现在只标记实际命中的无人区地块。
- 地理区域仍可保持一整片，其内部可以同时有中立、归属不同法理的地块，不必为政治标记切碎山脉或沙漠。
- `WildRegionData.neutralZones` 保存部分中立的地块编号；整片中立继续使用旧字段 `neutral=true`。旧档整片中立按原范围迁移。
- 合并、拆分时中立状态跟着原地块，不再跟随“重叠最多的旧区域”的整体标志扩散到其他地块。
- 神力“中立区”仍是整片开关：点击中立地块取消该片中立，点击非中立地块将该片整体设为中立。
- 编辑器预览、导出、悬停提示、自动开发和开发诏令结束判断同步使用地块状态。神力主动开发的既有授权不变。

中立不改变地表类型或通行能力。道路可穿过中立区；没有道路的山脉仍按现有规则阻挡。游牧、沙漠适应以及开发过半后的通行规则保留。

## 预设可明确指定当地法理

新增可选的 `wilderness_regions`，格式为“现有地理单元编号 → 现有地区编号”。例如：

```json
"wilderness": {"luliang": "tang"},
"wilderness_regions": {"luliang": "hedong"}
```

含义是在既有唐朝控制声明内，将吕梁山无人区明确挂在河东法理；并不把整条跨地区山脉都视作一个行政区。
没有对应国家声明、没有放得下的地方治所、地方城市属于其他政权时，不强行指定，沿用原有挂接。
同一帝国内的省份作为同一政权处理。明确法理编号在开局后独立存入 `world_map_wild.regional`，随法理本身流转。

归属优先级：游戏内法理神力笔刷 → 剧本明确的地块笔刷 → 明确当地法理 → 原行政锚点／国家级历史声明及现有自动挂接。
当地法理销毁后允许回退；首都法理消失时，仍存续的明确地方辖境可继续使用。旧存档缺少 `regional` 时不会自动套用新版预设。

数据来源为项目已有的地理单元、地区、开局控制声明与有效城表；没有借此新增国家领土，也没有把中世纪CK3归属套到其他年代。
选择的是粗粒度地区内的明确地理单元；生成器要求对应地区的有效城市全部属于原声明国家，并且最小地图至少有一座等级不大于2的城市。

## 交通走廊

复核了原有 `SilkRoadSystem`、`RoadNetwork` 和 `WildernessPassage`：剧本已有陆上丝路实际铺路，山口、城墙关门与路网规则已有实现。
本轮没有再添加一套平行走廊系统，也没有把荒地改造成普通城市来放行。新增检查确认道路只解除所在无人区地块的阻挡，不放开其他无路地块。
离线检查不能保证所有大小地图上的每条丝路都已成功寻路铺成，仍须实际开局验证重点山口。

## 后续反馈：悬停帝国无人区不展开行政区

用户提供唐朝截图，国家颜色及帝国提示已经存在，但鼠标放在无人区时不显示地方行政区。
确认是显示入口漏接：普通／简化铭牌、帝国图层展开、帝国提示上下文及平滑画布的悬停省份都仅通过实体城市取国家，
而无人区的 `zone.city` 本来就是空值。并不代表这块地没有法理或行政承载城市。

已增加统一的 `WildernessTerritory.KingdomAt`、`AdministrativeCityAt` 查询：真实城市优先，无人区取实际归属和仍属同政权的承载城市。
普通画法和平滑画法都可显示鼠标所在行政区的颜色；帝国名称的展开及提示框沿用同一上下文。
平滑画布在移入、移出时将远处无人区一起标记刷新，不把这次显示变化当作政治换主，不修改平滑取样和实际法理。
无人区提示缓存也区分具体地块和无人区版本，避免在同一山脉内移动后继续显示上一块的法理。

专项入口 `pwsh -NoProfile -File Tools/WorldMap/check_wilderness_hover.ps1`：21项生产方法检查通过，涵盖真实城市、所属行政区、
同帝国其他省、外国承载城市、中立区、封建附庸、帝国提示、普通画法、平滑画布及移开恢复。
另通过帝国提示31、简化铭牌20、原采样5、显示刷新29、共享轮廓88项既有检查；编译0错误，仍有15条既有警告。
这部分为显示修复，重启加载新版模组后可直接用于旧存档，不要求重建地图；没有进行游戏内实际游玩验证。
