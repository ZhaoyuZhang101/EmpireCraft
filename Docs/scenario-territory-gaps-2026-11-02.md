# 历史剧本延迟初始化后国土出现缺口

用户反馈：开局地图一度完整，经过卡顿和后续加载后，山地、高原一带出现未染色缺口。

## 现场证据与复现路径

读取本机 `WorldBox/Player.log` 的盛唐开局记录：

- 开局铺满后，历史雨林大泽初始化触发首次无人区划分。
- 该轮划出118片、10017个无人区地块，其中6336块原来属于城市；划分耗时876毫秒。
- 下一条国土挂接日志记录10017块均已并入105个国家，说明这一阶段不能将所有显示缺口归结为“没有归属”。
- 后续重划的无人区数量持续下降。生产代码在地块退出无人区后没有保存独立的国土来源；退出后的无城地块又无法在固定城市领土模式下自动恢复。

本轮分别覆盖两条可复现路径，没有声称凭日志已逐像素定位截图中的每一处缺口。

## 修复

1. **已知归属的填色回退。**平滑画布的城市轮廓已经让出的格子，可能在无人区外沿或山谷得到空的形状／候选结果。
   `FillAt` 现在保留有效的原平滑结果；结果为空时使用该地块已经明确的填色归属。真正没有归属的地块仍返回空，水面继续由调用方排除。
   B样条、噪声、候选权重、通用分区算法均未更改。
2. **保留行政来源。**在历史雨林改造、无人区收地之前，保存实际城市辖地的来源；之后每次重划、保存时也记录有效无人区的法理与承载城市。
   新的可选存档字段 `world_map_wild.territory` 保存“地块 → 城市编号、法理编号”。
   地块因地形变化退出无人区后，若仍无实体城市且仍是陆地，政治／法理图层可继续使用这份已知来源，悬停沿用相同上下文。
   法理持有者变化时按现有归属规则跟随；有实体城市时由真实城市优先。明确中立的来源被移除。
   这属于历史地块的归属呈现，不新建虚构城市，不增加人口或税收，不绕过城市地块上限或法理容量。
3. **加载收尾。**没有雨林大泽改造的剧本，也会在加载收尾调用 `EnsureBuilt` 完成首次无人区划分；已经划好的不再重复整图重建。
   不再仅依赖进入世界后的第一次常规更新。
   加载遮罩从固定30秒超时改为连续30秒没有进展才超时：仍在处理城市和收尾队列时不会因总时长超过30秒就提前揭开，停滞时仍有退出兜底。
4. **同帝国内部改隶缓存。**两个省显示为同一个帝国时，不能仅比较帝国显示对象决定缓存是否变化。
   国土呈现还会比较实际归属国，避免行政区名单、悬停和重画缓存继续指向原省。

只使用已有明确来源，不给未知区域、海面或真正中立区随意分配国家。地块仍可归无人区或无实体城市的行政范围，不必全部塞回城市。
