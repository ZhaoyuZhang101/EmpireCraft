# 无人区随城市行政变化更新

用户反馈：城市行政变化后，山地等无人区仍留在旧行政区，形成类似飞地的残片。

## 原因与处理

- `Attach` 反复应用剧本的地方默认法理，可能把已经改隶的辖境恢复为开局归属。现在地方设置用于初始化；已有有效来源城市后，自动辖境跟随城市，编辑器与神力笔刷仍保持明确指定的优先级。
- `OriginOf` 原先只接受仍属于旧法理的来源城市。来源城市换法理后，会从旧法理里另找城市，旧法理即便仍存续也会留下错误残片。现在自动辖境保留来源城市，更新为该城的当前法理；城市暂时无头衔时也保留来源关系。原城市消失后仍沿用既有的替代城市修补规则。
- `TitleSignature` 原先漏记城市所属国家、省份和帝国；直接累加法理编号也无法识别两城互换法理。现在把每座城市的身份、法理、国家、帝国和游牧状态关联计算，成员变化触发地图刷新，单纯枚举顺序变化不触发重挂。
- 已退出无人区的山谷等土地仍有保存的历史范围来源。这些记录现在跟随原城市的当前法理，避免旧缓存再次画回旧辖境。手动画定的记录用可选 `pinned` 字段保存固定法理，读档后继续保留；相应行政图层也使用固定法理下的城市。
- 保存和重新划分时先核对来源，再读取法理，防止同一次保存中写入新来源、旧法理的组合。

未改动法理兼属、头衔持有者判定、原平滑采样或城市地块上限；永久中立仍不产生政治归属。普通国家归属继续采用原法理持有者和同帝国省份的判定规则。

## 验证

`Tools/WorldMap/check_wilderness_administration.ps1` 直接提取生产方法，验证原城市换法理、地方默认不回滚、重复刷新、保存一致性、手工笔刷保留、临时无头衔、同法理改省、帝国变化、两城互换法理，以及原有的建城、毁城、法理解散和旧档恢复行为。

`Tools/WorldMap/check_wilderness_policies.ps1` 补充退出无人区后的行政跟随、固定法理和无头衔情况，并验证 `pinned` 的 JSON 往返保存。原悬停显示、城市地形扩张、剧本分区与原平滑采样检查继续执行。

新版本读档后可以根据仍保存的来源城市更新自动辖境。若旧版本已经丢失、改写了来源城市，无法仅凭截图或当前颜色可靠推回原始辖境；不会按最近城市全图重画来猜测。未进行游戏内实测。
