# 科技回退神力 说明与测试清单(2026-11-07)

群友(用户转)："各位有没有什么保存当前地图城市边界的同时，能把文化全部退回原始时代的方法？我整了半天，让他们一个个科技都成为原始，但问题很快他就反弹了"。用户："单独做个godpower来回退科技"。

## 一、两个神力(文化与营建页 · 易俗一组，复旧法理后面)

- **科技回退**(`tech_rollback`，点城)：城所属国家的文化(同科技窗口，`TechnologySystem.GetCultureOf(city)`)退回上一个时代——当前时代档及以上的科技连同以它们为前置的后续科技全部删掉；已在石器时代的退回原始(一项不剩)；已在原始时代的提示"无可再退"，仍把缺科技的制度、超出科技的建筑清一遍。屏幕提示新旧时代与删了几项科技、撤了几项制度、几座城排队降级；世界日志一条"X文化的科技由A退回了B"，本文化各帝国史书各记一条。
- **举世退回原始**(`tech_rollback_world`，按钮)：第一下预备(提示 5 秒内再点确认)，5 秒内第二下执行：存过科技/制度的文化与眼下有国家、有城的文化一齐退回原始时代；世界日志"天下文明尽归草昧"，所有帝国史书各记一条。
- 世界法则「文明科技树」关着时两个神力都只提示，不动。
- 城界、地块、国家、帝国、人物与人口一概不动。

## 二、以前为什么反弹

| 途径 | 位置 | 现在 |

| 海军、传播媒介补记 | `BackfillNavalLine`、`BackfillMediaLine` | `naval_line`、`media_line = true` |
| 科技点储备第二年一口气买回来 | `research_bank` | 清零 |

## 三、退了什么

1. **科技**(`TechnologySystem.RollBack`)：删掉的科技视同从未研究——研究进度、在研、玩家目标、加速事件记录、获得时间清掉，退回时代以上的在研进度也清掉；科技点储备清零、经费不足记录清零、士兵换装停下；时代记录改成新时代(以后重新进时代照常写"迈入"日志)；各国采纳记录(独立国按本国文化、帝国按核心国文化)去掉退掉的科技。
2. **材料**：只遗忘绑在科技上的(`TechMaterialConfig.requires_techs` 不全了：铁、煤要深井采矿，硝石要炼丹，石油要工业化，铀要电力)，要这些材料的科技连带删掉；木、石、皮、铜、金银、秘银、精金只靠资源发现，不动(明年照样从城里资源发现)。
3. **制度**(`TechRollbackSystem.RevokeInstitutions`)：已施行却缺了所需科技(节点 `requires_techs` + 按特性挂的 `institution_links`，科技树里没有的 id 不算)的制度，走制度窗口「回退此制度」同一条路(`InstitutionSystem.ForceRevokeNodes`，不逐条发消息)：连同后续制度撤下，被取代的旧制度恢复，恢复的也缺科技就再撤一轮(至多 16 轮)；在推的改革目标缺科技或前置的作废。
4. **政体**：由制度反推，不当场强改。各国照原有的逐国跟进(`InstitutionSystem.TryAdvanceRegimeTransition`)在 2~5 年内退回本文化剩下的最高君主政体(如律令 → 周制)；退到原始阶段(根节点是原始政体)时，已成形的王国、帝国按原有规矩保留现政体(不把帝国打回部落、赶走成员)；共和、现代由共和体系管。
5. **建筑**(`TechRollbackSystem.Tick`，每帧 3 毫秒时间片，大城一帧过不完下一帧接着过)：城里要某项本文化没有的科技的建筑(`GetRequiredTechForBuilding`)——
   - 顺着升级链往下(谁的 `upgrade_to` 是它，几座都升到同一座取同类型、等级最高的；再看 `upgraded_from`)找本文化能建的最高一级；
   - 民居：先在同一块地上找空处盖低一级的、再拆旧的，不留住房空档；链上找不到的用本城建造单里科技许可的最高一级民居(`CityZoningSystem.BestAsset`)；都没有就留着；
   - 别的建筑：拆了在原处补盖(拆除动画走完才腾出地方)；4 秒还没腾出来改在本块地、本城别的地块(至多 12 块，民居不去沙漠冻土)找地方；30 秒(不算暂停)放不下就算拆了，日志汇总一行；
   - 没有可降的拆掉(如原始时代的伐木场、屠宰场、园林)；在建的直接拆；
   - 城心的公所、篝火不动(拆了城没有城心)；文化城池 `city_<文化>_N`、村镇、厂区不受科技门槛管，不动；
   - 手动城区的城过完后对一次账(`CityZoningSystem.Later`)。
6. **不动的**：士兵身上已有的装备、已在场的载具(打造、换装、生产照新的科技卡口来；开局补齐本来就不按装备补科技，不会反弹)；已写成的时代名著；城界、国家、帝国、人口。

汇总日志：`[EmpireCraft][科技回退] 文化 X：时代 4(铁器时代) → 3(青铜时代)，删科技 n、忘材料 j、撤制度 m、降级建筑 k(另拆 r、留 q)`；举世一次另有一行总账。

## 四、边界情况

- 降级还没过完就存档读档：剩下的建筑留在原档次，但 `rolled_back` 已存进档里，不会按它们补科技；再点一下科技回退(已在原始时代也行)会把剩下的清一遍。
- 排队以后城易手给了别的文化：按新主人的科技，不在这里动。
- 回退以后才出现的新文化(比如易俗到一个从没出现过的文化)照常开局补齐，其中配置了开局制度(`start_institution`)的会带上那套制度要的科技——这是文化配置的开局，不是反弹。
- 周制统一改行律令、派系诉求转周制这类事件会照政体补记制度(`SyncEnactedNodeForRegime`)，只补制度、不补科技。
- 帝国核心文化与成员国文化不同时，只回退其中一个文化不动帝国共用的采纳记录(举世退回原始时全部清掉)。
- 连点：上一次的城还没过完又点了一次，并进同一本账；举世退回原始时单个文化的账并进总账。

## 五、游戏内测试

1. 开一张走到铁器以后的存档，打开某文化的科技窗口记下时代与科技数；选「科技回退」点它的一座城：提示"X文化退回…(原为…)"，世界日志一条，帝国史书一条；科技窗口时代退一档，最高一档的科技没了，储备为 0。
2. 连点同一文化的城，直到"已在原始时代，无可再退"；科技窗口一项科技都没有，铁、煤、硝石等材料没了，木石还在。
3. 制度窗口：缺科技的制度没了，被取代的旧制恢复；在推的改革若目标缺科技已作废。2~5 年后各国政体退回剩下的最高君主政体(退到原始阶段时保留现政体、帝国不散)。
4. 看城里的民居：高级民居逐一换成低一级(先在旁边盖、再拆旧的)，人口不因空房骤降；伐木场、屠宰场、园林等没有低一级的被拆；城心公所、文化城池不动。大图上不卡顿(性能面板"后台·科技回退"每帧不超过约 3~6 毫秒)。
5. 存档、读档：科技不反弹(读档后第一次结算后科技窗口仍是原始/回退后的时代)；过几年只按正常研究慢慢回升。
6. 「举世退回原始」：点一下只提示"5 秒内再点一次确认"；等 6 秒再点仍只提示；连点两下执行：提示 N 个文化、删科技、撤制度、几座城；所有文化都在原始时代；城界、国家、帝国、人口不变。日志里每个文化一行、最后一行总账。
7. 举世退回后存档读档、过 10 年：没有文化突然回到高时代；前代有帝国的文化不再白拿帝制；新称帝要重新推帝制(先研究科技)。
8. 关掉世界法则「文明科技树」后点两个神力：只提示没开启。
9. 降级过程中暂停：建筑照样逐城过，补盖等取消暂停后才放；降级过程中读另一个档：不报错，旧队列清空。
10. 装了 modernmod 的存档：6~11 级民居、3 级公所的城回退到铁器以前，民居降回原版档次，公所保持不动。
