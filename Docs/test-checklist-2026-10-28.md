# 测试清单（2026-10-28）

本环境没有游戏 DLL，代码未编译、未进游戏；以下项目需编译后实测。

## 王朝积弊与六弊互为表里(用户："但是这俩个也应该是有关联的才对")

- 以前只有六弊推高王朝积弊(六条平均/100 每年)，王朝积弊对六弊没有作用：明君能把六弊治到零，王朝积弊却只增不减，国祚近两百年"王朝积弊 11.8、六弊平均 0"。
- 现在反过来也连上(`MaladySystem`)：
  - 滋生：六弊每年的滋生 ×(1 + 王朝积弊/100)(积弊 100 时翻倍)；消退不打折；
  - 治不干净：每条至多降到王朝积弊的一半(积弊 60 的危局里各条至少 30，满额时至少 50)，整顿吏治等减项也止于这条线；年底低于这条线的浮上来(旧档、改朝换代后六弊先减了而王朝积弊还留着的)。
  - "朝政弊病"卡头一行的说明改为"随国祚累积，只能延缓；积弊越深，六弊滋生越快，治不到积弊的一半以下"。
- 验收：截图那个档(国祚 198、王朝积弊 11.8)下一年六弊各升到约 5.9；王朝积弊高的帝国明君在位也降不到一半以下；六弊推高王朝积弊照旧(满额时六弊至少 50，每年多涨约 0.5)。

## 人口：农田城人少、帝都不如别城、神力加的人一走就跌回(群友："城市A的面积是城市B的两倍……A还是帝国首都，人口只有一千多，城市B四千多""三个农田村的城市只有个位数人口……采矿伐木村的城市人口破千""我用工具调整人口，时间一走人口就立刻下跌回来了")

- 人口由什么决定：背景人口的硬上限是城里民居的住房位 × 每户人数(古代 100)；出生和"保底迁入"把人口推到上限，挤了、饿了、没活干就慢下来或往外迁。村镇不给住房，农田村只管口粮。
- 查出的原因与改动：
  - 盖房、升民居的木石在纯净地图下只能靠伐木村、采矿村，平原上全是农田村的城盖不起房、卡在住房上。新增"拾柴采石"(`PopulationEconomySystem.Glean`)：每户每年木 1、石 0.5，仓库里存到木 40、石 30 为止，不计产值。
  - 超员回落按年数线性乘(25%×年数)，游戏开快、一座城隔一年多才结算一次时一步全砍。改为 1 − 0.75^年数(`PopulationMathWorkers`)。
  - 神力"增加人口"刷到住房装不下的那部分另给容量(`CityPopulationData.brush_capacity`，计入城市人口上限)，留得住；"减少人口"同步收回。
  - 首都升级偏好(0.3 + 0.6×富庶 + 0.6)几乎回回先升级别的建筑，开工名额和木石被挪走。现在人口到住房上限九成、民居又没盖满时先盖民居(`CityConstructionSystem.StartNext`)。
  - 玩家给城设的"人口上限"按户记，无小人模式下当人数返回，开了上限的城被锁在一百来人；改为乘每户人数(`CityPatch.getPopulationMaximum`)。
- 验收：
  - 只有农田村的平原城仓库里慢慢有了木石，民居一座座盖起来，人口跟着涨；
  - 帝都住满时先盖民居，人口不再落后同等条件的别城；
  - 神力加人后跑几年，人口不再跌回(住房上限显示 = 住房 + 神力另给)；减少人口后上限一起回落；
  - 开了城市人口上限的，上限按户数 × 100 人算。
- 没动的(设计取舍，另议)：粮赋按收成抽(统购统销抽七成)、可耕系数按全城陆地算(扩地多了山林，农田村产量被压低)、城市面板"增长"只显示出生减死亡(不含超员回落与迁徙)、住房为零的自发聚落没有保底迁入。

## 可耕系数按田在哪算；粮赋只从余粮里征(用户："可耕系数和粮赋也改一下")

- 可耕系数(`FarmlandSystem.ArableFactor`)：以前按全城陆地算，城一扩张多了山林，所有农村的收成都被拉低。现在只看田在哪——各完好农村所在的地块连同本城的四邻地块，加上城郊(城心地块连同四邻)；这些地里可耕格占六成以上照常收，越少收得越少，最少三成。
- 粮赋(`GranarySystem.Collect`)：以前按收成整份抽(征收粮赋三成、统购统销七成)，农田村越多被抽得越多，种粮的城自己不够吃，再靠打了折的赈灾调回来。现在先留足本城的口粮：余粮比例 = 1 − 户数×0.5 / 上年收成(交粮仓之前，`CityPopulationData.last_harvest_gross`)，只从余粮里按政策抽；上年收成还没结算过的不征。
- 验收：
  - 同样几座农田村，城扩张到山地后收成不再整体下降；农村都在平原的山城收成照常；
  - 统购统销下，农田城留下的粮够本城吃，不再年年缺粮等赈灾；国家粮仓的进项比以前少(只收余粮)；
  - 新开局或旧档读档后头一次经济结算前不征粮赋，之后正常。

## 主城也有和村镇一样的小窗口(群友："可以给主城设置一个界面吗……村庄界面……可以直接修改样式那个界面")

- 纯净地图拉近到街道一级，点主城的城区(建成的城里那几格)打开城池小窗口(`MapLabelOverlay.HandleClick` → `CityStyleWindow`)；点村镇、厂区照旧开它们自己的。「城貌」神力照旧也能打开。
- 窗口改成同村镇小窗口的版式(标题"城池")：
  - 左「城池」：城名与国家、现在的城貌、现文化的风格、随风格走的规矩(原有)；
  - 右「营建」(新)：约多少人(几户)、住得下多少人；民居几座/上限、富庶几成；城郊各生计的村镇份数(务农、伐木、采矿……)；按钮「繁荣」(同神力笔刷刷一下)、「加人口」「减人口」(同神力笔刷一下，住房装不下的部分另给容量)、「营宫殿」(同神力，五秒内再点一次才营建)；
  - 下「城貌」(整宽)：各文化系画法与「照现文化」，一行五个(原有，挪到下面)。
- 验收：街道级别点主城城区弹出城池窗口，各按钮生效、窗口数字跟着刷新；点村镇仍开村镇窗口；点城外空地不弹窗。

## 穿越政体(临高启明·澳宋)第一期

- 来由：按小说《临高启明》做单独的穿越政体，五百多名穿越者凭空降临，国号从临高元老院走到大宋澳洲行在。
- 现在：
  - **穿越降临**(帝国页权能，元老院旗图标)：点哪里就在最近的空海岸凭空出现一座城和一个新国家。附近有叫临高的城或村镇时，营地叫百仞，国号仍是临高元老院；没有时落脚的城就叫临高。海岸都被占了，就从别人城里切一块岸边地块。一个世界同时只有一支穿越者。
  - 降临当场：两千人口(五百二十一元老加首批归化民)、五千国库、伏波军五百人(线膛枪)、三艘战船两艘运输船、码头与城里各类建筑、一处厂区，城貌按工业时代画；科技火药时代以前全会，工业时代各项先有一半进度。国旗是启明星旗(原版调色板里最接近的深蓝白配色，地图色深蓝)。
  - **澳洲人文化**：人名用现代中国词库，天下归华夏，走自己的澳宋制度线。
  - **穿越政体**：元老院五百二十一席固定，元老故去由子女一人继承，永不空缺。名字、职务照原著人物记(`Scripts/Regimes/Configs/Transmigrant/Senators.csv`，236 人)，其余自动起名。
  - **执委会主席**：由元老院从元老里选，任期四年、可连任一次，连任两届后隔一届。主席故去当场补选。不称帝、没有天命世袭。
  - **四个阶段**(制度树)：降临·临时执委会 → 第一届执委会(两城起) → 共同纲领·第二届执委会(五城起) → 大宋澳洲行在(十城起，国号改大宋澳洲行在)。另有伏波军、出版指导小组、企划院、政治保卫总局、对外情报局几项。
  - **出版指导小组**：每五年刊行两部书，只放比本国落后两个时代以上的冶金、营造、格致类技术，接触到的文化与治下城的文化各得三成进度；兵书、政论不外传。
  - **两面旗**加进原版旗帜纹样表末尾(星拳旗、启明星旗)，别的国家也能选。
- 验收：
  - 新开一张图，在海边用穿越降临：屏幕出一条大事，第几年某城海滨凭空出现五百二十一人；国名是临高元老院，旗帜是蓝底白色启明星，政体窗口显示穿越政体(红底黄齿轮按钮)。
  - 国王叫文德嗣，城主叫马千瞩，名臣有萧子山、邬德，名将有何鸣；点开人物，履历里写着第几席元老和职务。
  - 科技窗口：火药时代以前都已研究，工业化等有一半进度；城里有码头、厂区，海上有一支舰队。
  - 跑十几年：日志有元老故去、席位由子女继承；四年一次全体大会改选，文德嗣连任一次后换人。
  - 打下两城、五城、十城：制度树依次推行，大事里出现第一次全体大会、共同纲领；十城以后国名改为大宋澳洲行在。
  - 出版指导小组施行后五年：日志有"出版指导小组刊行《……通俗读本》，传入 N 个文化"。
  - 在别的地图上再点一次穿越降临：提示"穿越者已经降临过了"。

## 殖民体系：总督府、特许公司、殖民船

- 来由：给穿越政体和以后的公司政体、总督打底。问答定：殖民地是附属政权；海外城自动编入，加上主动殖民；公司政体一起做(研究出金融以后)；研究出远洋航海的都能殖民。
- 现在：
  - **殖民地自成一国**，记着宗主国。宗主与殖民地、同一宗主的殖民地之间不开战；殖民地随宗主出征，宗主保护殖民地。地图上是自己与宗主的合成色。殖民地不再认别的宗主、不入帝国、不称帝，城池算到宗主名下。
  - **编入**：本国采纳了远洋航海，海外城(行政控制力判定必须走海路、不在都城那座岛、离都城 36 地块以上，又不是半壁江山)每年按岛编成"<首府>总督府"；那座岛上已有本国殖民地的就并进去。
  - **殖民船**：每年三成五的机会、八年冷却，花 600 两，挑海路够得着的别的岛上的无主海岸(本国市场缺的物资出产的地优先)。航行几个月后建城，从都城迁去 300 人，编进殖民地。本国研究出金融以后，六成交给特许公司经营("<宗主国><首府>公司")。
  - **总督府**：总督由宗主国派，任期六年。穿越政体的宗主派元老去当总督。每年把经常收入的三成解送宗主。
  - **特许公司**：董事会选总督，自己养兵开战。国库超出储备的余钱每年一半分红给宗主。做到六座城，或亏空成债满十年，就被收归国有、改设总督府。
  - **离心**：路远、宗主不如自己强、宗主在打仗就涨，满了且立满三十年就起兵独立(附庸独立一类战争)。打赢就脱离，按本文化重定政体；打输压回三成。宗主亡了当场自立。
- 验收：
  - 西方大国研究出远洋航海后跑几十年：日志有"某国的殖民船队从某城起航""登岸，建起某城""在海外设某某总督府，派某某为总督"；研究出金融后出现"某某公司"。
  - 殖民地与宗主不互相宣战；宗主开战时殖民地跟着参战；别国打殖民地时宗主来援。
  - 政体窗口：总督府是殖民地政府，公司是特许公司；殖民地的首领称总督。
  - 总督府六年换一任总督；公司做到六城时日志有"收归国有，改设某某总督府"。
  - 宗主衰弱、打仗时，殖民地起兵独立；打赢后国名去掉"总督府"，地图色变回自己的。

## 商品市场：二十来种物资、大国市场与关税同盟、奢侈品

- 来由：参考维多利亚三。大国组建市场，物资交易流通；缺物资就生产不了，相应的科技、商品也发展不了；还要有奢侈品。这样殖民就有了动力。问答定：四档二十来种物资；大国领衔加关税同盟；缺货卡科技、工厂与兵种、奢侈品与民心；市场窗口并进外交界面一起做。
- 现在：
  - **物资**(`Technology/Commodities.json`)：
    - 基础：粮、木、石、金属；
    - 原料：铜、铁、煤、硝石、石油、棉花、橡胶；
    - 制成品：布匹、工具、军械、钢材；
    - 奢侈品：丝绸、瓷器、茶、香料、糖、烟草、酒、珠宝。
  - **产出**：物资账上一年的产出、城辖区里的群系乘人手、本文化手艺、工厂。棉花、橡胶、香料、糖、烟草主要出在热带的丛林、草原、沼泽；丝、瓷、茶靠华夏一系的手艺。
  - **需求**：各阶层每千人的用度(奢侈品主要是贵族、官僚、商人、市民)、工厂投入、军队(打仗翻倍)。
  - **市场**：每个独立国领一个市场，附庸、殖民地、帝国成员、朝贡国都算进宗主的。国力前八是大国。接壤大国、对它好感好、比自家缺得少的小国，每年两成机会签关税同盟并入；交战、反目就退出。
  - **市场之间**：陆上接壤或商路相连的市场，缺的向有余的买，付价款另加两成关税，记公家贸易。价格按供需在 0.25~4 倍之间浮动。
  - **缺口的后果**：
    - 科技研究离不开的物资缺多少慢多少，最慢三成(没煤铁难工业化、没硝石难火器、没石油橡胶难机动化)；
    - 工厂投入不足减产，最多减八成；
    - 兵种换装缺过一半就换不了；
    - 奢侈品满足度：城的自然稳定 ±4，税 ±5%。
  - 每年日志 `[EmpireCraft][市场]`：前五个市场的成员数、外贸额、缺什么。
- 验收：
  - 跑一年：日志有 `[EmpireCraft][市场] 某国(大国) 成员 N 国，外贸 …，缺：…`。
  - 城市稳定度的来由里出现"奢侈品满足 N%"。
  - 小国日志有"与某国订立关税同盟，并入其市场"。
  - 缺煤铁的文化研究工业化明显变慢；缺硝石的国家火枪兵换装停住。
  - 殖民船多半去热带的地方(缺香料、糖的大国)。

## 穿越政权扩张：流民投奔、开拓新城、伏波军、用兵、元老保护、带来的现代技术

## 游牧城圈荒地不圈到别国门口

- 来由：玩家问游牧城边界为什么会动；用户定"外长可以，但是不要把别国的土地也给吞了"。
- 查明：游牧营地每月领挨着的纯沙漠、纯冻土(10-22 定，至多常规上限两倍)，有主的只从本国别的城接；劫掠之战只抢不占；自动扩张只领无主地。漏洞在无主地只跟收荒地的城比远近，游牧营地远近放宽两倍，别国城门口的无主沙漠也圈走。
- 现在：无主的荒地挨着别国的城、那座城的城心比游牧城近(或一样近)就不领，留给别国。
- 验收：游牧国与定居国隔着沙漠接壤，跑几十年：游牧城往空沙漠里长，但不贴着别国城心圈地；别国已有的地一块不少。

## 皇帝换姓(群友："这种现象确实挺常见，皇帝开始换姓了"；用户："为什么皇帝会换姓")

- 原因：
  - 孩子入哪一族，以前只有在位君主、储君一方和华夏一系(宗法父系)有定规；别的文化按原版的男先/女先随机，两边都"够格"时谁排前面算谁，皇子还没立储时生的孩子常入了母亲那一族、随母姓；
  - 立储时先君的子女不论在哪一族都算，生在母亲那一族的皇子照样立为储君；
  - 即位时虽会把新君挪回皇族，但只有华夏一系跟着改回皇族的姓，别的文化新君名字还挂着母亲的姓，帝王表上一代一个姓。
- 改动：
  - 宗室(生在统治某国、某帝国的世系里、又是这一族继承性别的本宗族人)的子女入宗室、随宗室的姓(`SurnameInheritanceSystem.Dynasty`；两边都是宗室的，帝国皇族先于王族)；
  - 立储时本宗世系里的子女先于生在别的宗族的；先君亲生、却在别的宗族的子女一旦立为储君就认祖归宗，入先君的宗族、随先君的姓(`EmpireCraftKingdomBehCheckHeir.ReturnToLine`；外家入继、兄弟旁支不挪)；
  - 即位挪回皇族时，名字里带姓的文化都改随皇族的姓(`Empire.RestoreDynasticSuccessorClan`)；名字本来不带姓的文化不硬加。
- 验收：非华夏(日本、西欧等)帝国、王国传几代，皇帝、国王一直同一个姓；皇子的孩子入皇族；截图那种"父慕容光、母艾拉龙痕、姓龙痕"的储君下一次复查储君时改姓慕容、入慕容氏；外家入继(女系继承的西欧王国)照旧换家族。
