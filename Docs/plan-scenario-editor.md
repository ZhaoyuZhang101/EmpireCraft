# 剧本编辑器方案(2026-10-30)

## 用户要求

- "能不能加一个允许玩家编辑剧情或者创造剧情，可以是架空也可以是基于我已经给过的预设，但是需要简单易懂，上手快"
- "避免卡顿：地图的显示用像素图预览，不用真的加载进去地图；编辑法理和城市也直接在像素图里做，就像之前写的全屏城池编辑一样"
- 剧情事件：要，用选项拼搭(不写代码)
- 剧本存成文件，可以分享
- "地图也可以玩家自己导入"

## 总体思路

剧本编辑器是一个全屏窗口(仿 `CityPlanScreen` 城池全图)，**全程不生成世界**：左边一张像素地图预览，右边是工具栏和当前选中对象的属性。编辑的是剧本数据本身(与 `WorldMaps/eras/*.json`、`cities.json` 同一套格式)，保存成一个剧本文件；开局时照现有世界地图剧本的流程(`WorldMapGenerator` → `WorldMapScenario`)一次性生成。

## 剧本文件

- 一个剧本一个文件夹：`mods_config/EmpireCraft/scenarios/<剧本名>/`
  - `scenario.json`：就是一个时代文件(`WorldMaps/eras/*.json` 的全部字段：剧本名 zh/tw/en、简介 dzh/dtw/den、开局年份 year、东西方 focus、
    国家 polities、帝国法理 cores、关系 relations、长城关隘 walls/passes、科技与制度、无人区归属……)，另加：
    - `author`：作者；
    - `regions`、`cities`、`tianxia`(可选)：自带整套城表(写法同 `cities.json`)，用于架空地图；带了的话帝国法理只用本剧本 cores 里写的，
      不带就用内置 `cities.json` 的城表与通用帝国法理(从预设复制来的剧本都不带)。
    - 剧情事件(第四期)以后另加一节。
  - `map.png`(可选)：玩家导入的地图；没有就用内置的地球地图(`earth.bytes`)与范围、大小档位。
  - `preview.png`：剧本列表里的缩略图(保存时自动出)。
- 分享：把文件夹整个拷给别人，放进同一目录，剧本列表里就能看到。

## 编辑器(全屏，像素图)

- 地图预览：内置地图按 `earth.bytes` 直接画成一张贴图，导入地图直接读 PNG；拖动平移、滚轮缩放，一格一像素放大显示，不进原版世界。
- 图层切换：地形 / 王国法理 / 帝国法理 / 天下 / 国家，颜色同游戏里的图层。
- 工具(左侧一排按钮，选中后在图上点或刷)：
  1. **城市**：点一下放城，填城名；拖动挪位；右键删除。
  2. **王国法理**：笔刷把城刷进某个王国法理(新建、改名、合并)；兼属用另一个笔刷挂第二上级。
  3. **帝国法理与天下**：选若干王国法理归入某个帝国法理，帝国法理再归入天下。
  4. **国家**：点城定归属，"新建国家"填国名、文化、政体、都城、君主(姓名、年龄)，可加宗室几人；宗主/附庸/朝贡从下拉选。
  5. **关系**：两国之间选结盟、交战、和亲、通好、朝贡、关税同盟、旧谊、宿怨(即 `DiplomacyActions.ApplyScenario` 的种类)。
  6. **长城与关隘**：在图上点几点连成一段长城，点一下放关隘。
  7. **剧情事件**：见下。
- 右栏：当前选中对象的属性卡片(卷册样式)，改完即时反映在预览上。
- 撤销：每步存快照，至多 30 步。
- 起点三选一：从某个预设剧本复制、空白剧本(选地图档位)、导入地图。

## 剧情事件(选项拼搭)

一条事件 = 时机 + (可选)条件 + 结果，全是下拉与点选：

- 时机：开局第 N 年、某年；每年检查一次。
- 条件：某国据有某城 / 某法理过半；某国灭亡；某国称帝；两国交战中；某国王朝积弊高于 N。
- 结果：称帝(定国号)、改国号、迁都、宣战、议和、结盟、称臣纳贡、立某人为君、采纳华夏制度(入主)、改文化、发生政变/起事。
- 一次性或可重复；触发时进史书与屏幕提示。
- 预设剧本里写死的(后金入关称大清、穿越者降临)将来也改用这套事件表达。

## 导入地图

- 支持一张 PNG：按颜色认地形(深海、浅海、平原、草原、森林、丘陵、山地、沙漠、雪原、沼泽，给一张颜色对照表)，或灰度高程图(选海平面阈值)。
- 导入后先在预览里显示，确认大小档位；开局时照 `EarthTerrain` 的流程铺地形、补河流(没有河流图就不铺)。

## 分期

1. 剧本文件读写 + 剧本列表(新世界模板窗口里与预设并列) + 开局载入玩家剧本(复用 WorldMapScenario)。**已做(10-30)**：
   - 世界地图窗口多一张「自定剧本」卡，列出剧本文件夹里的剧本，选了与预设一样开局；剧本说明卡写作者、自带城表几城、对不上的地方
     (都城、地区不在城表里，国家编号重复，关系里写了不存在的国家；开局时那几条跳过)；
   - 选中预设时「存为自定剧本」：原样拷那个时代文件进剧本文件夹(文件夹名=预设编号，重名加 _2…)，剧本名加"·自定"、加作者一栏；
     「打开剧本文件夹」「刷新」；
   - 代码：`WorldMapData.LoadCustom/CopyAsCustom/Activate`(开局时按剧本换城表，自定剧本编号为 custom/<文件夹名>)，
     `WorldMapEra` 加 author/regions/cities/tianxia，`WorldMapGenerator.Start` 开局前 Activate；
   - 第一期还没有编辑器，剧本先手改 json；缩略图 preview.png、导入地图 map.png 随第二、五期。
2. 全屏编辑器：像素地图预览、平移缩放、城市与国家两个工具、属性卡片、保存。**已做(10-30)**：
   - 世界地图窗口「自定剧本」卡：选中自定剧本时「编辑剧本」，任何时候「新建空白剧本」(内置地球城各自独立、没有国家，建好直接进编辑器)；
   - `ScenarioEditorScreen`(全屏，仿城池全图)：地表像素图一像素 0.1°(`EarthTerrain.Preview`)，叠国家颜色(按开局归属预览从城往外铺陆地)、
     城点(都城大一号，选中描金边)，放大后写城名；滚轮缩放、右键中键拖动平移；
     工具：查看 / 城市(点空地立城、拖城挪位、右键点城两下删城) / 国家(点城选城与它的国家) / 划城(点或拖过城划给选中的国家，右键不再点名)；
     图层：地形 / 国家；看全图；
     右栏：剧本(名、开局年份、作者、简介)、城(名、大小档、地区、归属、经纬；立为都城、以此城立国、删城)、
     国家(名、文化前后换、开局称帝、君主姓名年龄；删国家)；保存写回 scenario.json 并出 preview.png，关闭有没保存的改动要五秒内再点一次；
   - 数据一侧 `ScenarioEditing`：归属预览照开局规矩(点名的城与都城在先、地区认领归最近都城、没人认领独立)；
     头一回增删挪改城时把内置城表(地区、城、天下名、通用帝国法理)整套拷进剧本；城的大小档只记 ranks；改名三种写法一起改；
     只写字段、空的不写；
   - 还没有：撤销(第三期)、法理与关系、长城关隘工具(第三期)、城的地区归属改动(第三期法理工具里做)。
3. 法理(王国、帝国、天下、兼属)、关系、长城关隘工具；撤销。**已做(10-30)**(用户另要"法理首都的调整""帝国核心法理首都")：
   - 工具栏分两行：工具(查看、城市、国家、划城、王国法理、帝国法理、关系、长城、关隘)；图层(地形、国家、王国法理、帝国法理、天下)与撤销、看全图；
     法理图层在各块辖下城的正中写法理名、帝国法理名、天下名，选中的那块颜色深些；
   - 王国法理(=城表的地区)：点城选中它的法理；按住 Shift 点或拖过城划进选中的法理；右键点城切换兼属(至多两个)；
     右栏改地区名、法理名、文化，「立为法理首都」(新字段 regions[].cap，开局 BuildTitles 先认它，再是地区里的国都、最大的城)、
     「选中城另立法理」「删王国法理」(没城了才删)；
   - 帝国法理(=剧本 cores)：点城选中它所在的帝国法理；按住 Shift 点城把那城的法理收进来；右栏改名、「立为法理首都」(cores[].cap；
     开局称帝的国家照它自己的都城)、「以王国法理另立」「移出本帝国法理」「删帝国法理」，所属天下前后换、「新天下」、改天下名；
   - 关系：先点一国的城作起始，再点另一国的城，按右栏选的种类(DiplomacyActions.ApplyScenario 的 kind，交战另选战争目标)加上或去掉；
     选中国家的关系在地图上从都城连线，颜色按种类；
   - 长城：点一下加一个点(开局时两点之间沿山脊铺墙)，右键去掉最后一点，右栏换一道、新起一道、改名、删；关隘：点空处放、点了改名、右键删；
   - 撤销：每步改动前存一份快照(至多 30 步)，拖着划城、划法理是一笔；按钮与 Ctrl+Z；
   - 还没有：帝国法理兼收别的王国法理(cores[].share)、帝国法理兼属别的天下(cores[].tianxia)的编辑。
4. 剧情事件(选项拼搭)与运行时触发。**已做(10-30)**：
   - 数据：剧本的 events，每条 = 名、史书里的话、开局后第几年起、一次或可重复、条件(全部满足)、结果；条件、结果都是一条条
     {kind, a, b, city, region, value, name, relation, goal, culture}；
   - 条件：某国据有某城、某国据有某王国法理过半、某国已亡、某国已称帝、两国交战中、某国王朝积弊高于某数；
   - 结果：两国关系(交战带战争目标、停战、结盟、和亲、通好、保护、朝贡、附庸、关税同盟、旧谊、宿怨，走 DiplomacyActions.ApplyScenario)、
     称帝(可定国号)、改国号、迁都、改文化、采纳华夏制度(入主，国号照写的定，借 CompositeEmpireService 的剧本国号)；
   - 编辑器「事件」工具：右栏选事件、新事件、删事件，填名、史书、开局后第几年、一次或可重复；条件、结果各一条条加，种类前后换、×删；
     国、城、法理三项点按钮后再点地图上的城填进去(国取城的归属，法理取城的王国法理)；数值、国号填框；关系、战争目标、文化前后换；
     右栏改成可上下滚；
   - 运行时 `ScenarioEventSystem`：开局(WorldMapScenario.Finish)记下事件表与剧本的国/城/地区对上的国家/城/王国法理编号，随存档保存
     (SaveData.world_map_events)；每年查一次，满足就照结果做、写进史书上屏幕，做不了的记日志；
   - 还没有："立某人为君""政变/起事"两种结果；预设剧本里写死的(后金入关称大清、穿越者降临)改用事件表达。
5. 导入地图(颜色地形 / 灰度高程)。**已做(10-30)**：
   - 剧本的 map 一节 {mode: color|height, sea}，图是剧本文件夹里的 map.png(`WorldMapImporter`)；一像素一格、每格 0.1°，经纬度从左下角 0 起，
     城就按这个记；图太大的缩到 2048 以内；
   - 颜色图按最近的颜色认成地形(颜色同编辑器的地形预览，对照表写进剧本文件夹的 map_colors.txt)；灰度图按海平面分深海、近海、浅滩，
     陆地按高低分沙滩、平原、高原、丘陵、山地、雪丘、雪山；
   - 开局：`EarthTerrain.UseGrid` 换上导入的网格(其余剧本 UseEarth 换回地球)，范围照图，三档大小一像素一格、一格半、两格(4~48 区块)；
     不画地球的大河、不按地球地理给无人区起名；世界地图窗口里这类剧本只选大小，写"导入地图 宽×高"；
   - 编辑器剧本卡「地图：地球 / 导入」切换(清空城、国家、法理、关系、长城与事件，五秒内再点一次，可撤销)；导入时选读法(颜色/灰度)、
     海平面，「读入地图」重读 map.png(没放图时显示一片海)，「打开剧本文件夹」；
   - 还没有：河流图、文件选择框(图要自己放进剧本文件夹)。
6. 笔刷、部落圈、半幅地图(用户 10-30 追加)。**已做(10-30)**：
   - 剧本数据：paint(刷的地块归属，0.2° 一格，键 "p:国家"/"r:王国法理")、terrain(刷的地形，0.1° 一格 → 地块写法)、tribes(原始部落圈
     {at, radius, culture, count})、frame(地图范围)；格子按经纬度绝对编号(`ScenarioCells`)，与地图范围无关；
   - 开局：`EarthTerrain.SetOverrides` 铺地表时刷的地形盖过网格；`WorldMapScenario.PaintTerritory` 铺辖地前先把刷了的地块归那国(或法理)
     最近的城；`PlanTribes` 在补空小国前于圈里挑能建城的空地立部落(圈里不再补小国，补空时离部落也要够远)，进世界后改原始政体；
   - 编辑器：「刷地块」「刷地形」(左键刷、右键擦/复原，笔刷 0.2°~4°，拖着时图层颜色至多每 0.2 秒重铺)、「部落」(拖圈、点选、右键删)；
     刷的格子编辑时放字典，存盘与撤销快照前写回；图层颜色改按地形代价八方向铺开、两块相接处描边；工具与图层按钮配图标；
   - 半幅地图：`EarthTerrain.Frames` 加东亚(62°E~152°E，北到 62°N)与欧非西亚(26°W~64°E，含全非洲)，各三档大小；剧本卡「范围」记下，
     世界地图窗口选剧本时默认换到那档，编辑器画出框；
   - 还没有：笔刷刷"无人区/中立"、按法理边界自动描边的文字标注。

## 分工

- 用户定由世界地图会话来做(10-30)。
