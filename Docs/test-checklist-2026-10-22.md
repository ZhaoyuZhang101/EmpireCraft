# 测试清单（2026-10-22）

本环境没有游戏 DLL，代码未编译、未进游戏；以下项目需编译后实测。

## 全图律令制(玩家反馈)

- 原因：政体类型的默认值(枚举首项)就是律令。国家还没装上政体时(立国那一刻文化还没定下、或别处先取了政体)，一取政体就按默认值装成律令制；而政体迁移遇到原始政体的目标一律跳过，开局各文化都还在原始政体，这些国家就一直是律令制。以前只修过同类的"阿拉伯默认值污染"。
- 现在新建国家收尾时、每月国家例行检查身份时、读档迁移时都检查：律令制的国家，若本文化(连同所在帝国)此刻不该是律令——本文化制度树里没有律令，或本文化还在原始政体——就改回本文化的政体。日志 `[EmpireCraft] 修复国家 N 的默认值政体: LvLing -> …`。
- 新开图：头一两年各国应是各自文化的原始政体(部落、华夏原始、城邦共和等)，不应全图律令制；读一个已经全图律令制的存档，一个月内陆续改回。
- 不该动的：手选过政体的、共和锁定的、征服王朝的区域制度、水土改过政体的、华夏周制改郡县后的律令、帝国成员随核心的律令、日本律令国家以后的律令，都不应被改。
- 若仍有全图律令制：要玩家的 Player.log 和所用种族/文化(是否装了别的种族模组、种族有没有配文化)。

## 读旧档全图律令制、国名被改、文化图层没颜色、人口不长(同一根因)

- 原因：读档时模组存档里"人物附加数据"为空就整个返回(`DataManager.LoadAll`，10-07 起就是这样)，国家、城市、文化、人口、法理数据一概没读。世上一个实体小人都没有的世界(无小人、人口全在背景里；截图左下"智慧生物人口 0")存不出人物数据，于是一读档就丢：政体落回默认值律令、存下的国名没恢复而按缺省重起、文化绑定没导入所以文化图层没颜色、城市的背景人口没恢复所以人口不长。
- 现在只有整份模组数据读不出来(文件损坏)时才返回，并且照"没有存档文件"给各国按文化定政体；人物数据为空只跳过人物那一段。Player.log 里有"存档里没有人物附加数据(世上没有实体小人)，其余照常读取"。
- 验收：用出问题之前的那份存档(没有在坏版本里读过再存过的)读档：国名、政体、文化图层颜色、人口都应和存档时一样。
- 已在坏版本里读过并且又存过的存档：模组数据已被默认值覆盖，国名、文化等救不回来，只能用更早的备份。
