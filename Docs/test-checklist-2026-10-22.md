# 测试清单（2026-10-22）

本环境没有游戏 DLL，代码未编译、未进游戏；以下项目需编译后实测。

## 全图律令制(玩家反馈)

- 原因：政体类型的默认值(枚举首项)就是律令。国家还没装上政体时(立国那一刻文化还没定下、或别处先取了政体)，一取政体就按默认值装成律令制；而政体迁移遇到原始政体的目标一律跳过，开局各文化都还在原始政体，这些国家就一直是律令制。以前只修过同类的"阿拉伯默认值污染"。
- 现在新建国家收尾时、每月国家例行检查身份时、读档迁移时都检查：律令制的国家，若本文化(连同所在帝国)此刻不该是律令——本文化制度树里没有律令，或本文化还在原始政体——就改回本文化的政体。日志 `[EmpireCraft] 修复国家 N 的默认值政体: LvLing -> …`。
- 新开图：头一两年各国应是各自文化的原始政体(部落、华夏原始、城邦共和等)，不应全图律令制；读一个已经全图律令制的存档，一个月内陆续改回。
- 不该动的：手选过政体的、共和锁定的、征服王朝的区域制度、水土改过政体的、华夏周制改郡县后的律令、帝国成员随核心的律令、日本律令国家以后的律令，都不应被改。
- 若仍有全图律令制：要玩家的 Player.log 和所用种族/文化(是否装了别的种族模组、种族有没有配文化)。

## 读旧档全图律令制、国名被改、文化图层没颜色、人口不长(同一根因)

- 原因：读档时模组存档里"人物附加数据"为空就整个返回(`DataManager.LoadAll`，10-07 起就是这样)，国家、城市、文化、人口、法理数据一概没读。世上一个实体小人都没有的世界(无小人、人口全在背景里；截图左下"智慧生物人口 0")存不出人物数据，于是一读档就丢：政体落回默认值律令、存下的国名没恢复而按缺省重起、文化绑定没导入所以文化图层没颜色、城市的背景人口没恢复所以人口不长。
- 现在只有整份模组数据读不出来(文件损坏)时才返回，并且照"没有存档文件"给各国按文化定政体；人物数据为空只跳过人物那一段。Player.log 里有"存档里没有人物附加数据(世上没有实体小人)，其余照常读取"。
- 验收：用出问题之前的那份存档(没有在坏版本里读过再存过的)读档：国名、政体、文化图层颜色、人口都应和存档时一样。
- 已在坏版本里读过并且又存过的存档：模组数据已被默认值覆盖，国名、文化等救不回来，只能用更早的备份。

## 字体图集报错刷屏(玩家错误报告 error_2026_10_22_19_36_10)

- 现象：错误报告里 100 条全是 `Failed to update dynamic font (Roboto-Bold) texture; all the needed characters do not fit onto a single texture (max size 4096)`，帧率 29。
- 原因：领土铭牌(国名、帝国名)找不到合适的本机字体、或本机字体图集装满歇两分钟时，最后退回游戏的铭牌字体。那是原版城名和界面共用的动态字体，铭牌按 128 号字往里拼字，大地图上国名用字一多，图集装不下，每帧报错，原版的字也跟着变空白。
- 现在最后的兜底换成模组自建的一份本机字体(微软雅黑、黑体……依次找)，图集单独一张，装满了也只影响领土铭牌。选了"游戏字体"的玩家，铭牌的英文字母会从 Roboto 变成本机无衬线字体，汉字基本不变。
- 验收：大地图、国家多、铭牌字体选"游戏字体"或本机没有隶书时，开着国家/帝国图层来回缩放几分钟，错误报告里不应再有 Roboto-Bold 这条；原版城名、按钮上的字不应变空白。

## 读档链加固(接上一节)

- 模组存档文件损坏(截断、格式坏)时，以前读 JSON 直接抛异常，被外层接住后一个国家也没定政体，照样全图律令；现在接住，当作读不出来，各国按文化定政体。日志"模组存档读不出来(文件损坏？)"。
- 读档链上各段(帝国成员整理、帝国整理、帝国核心修复、兼属、水土羁縻、文化数据迁移)和两个国家循环各自接异常：一段出错只记日志 `读档[…]失败，已跳过这一段`，不再让后面的定政体、国名、帝国迁移全部跳过。
- 古战模组的国家在"没有存档/存档读不出"时也不再被按文化定政体(同读档末尾的循环)。

## 文化图层有字无色(接上一节)

- 找不到原版文化对象的城(世上没有实体小人的世界建不出原版文化；坏版本里存过的档已经丢了)以前整城跳过；现在按铭牌用的文化色画，铭牌和地块同色。
- 平滑国界(默认开)取文化图层每格归属，以前按城市身上的原版文化取，对不上的城被平滑成透明；现在和文化图层自己的画法一样按模组主流文化取。流动区块(按人口分布)那一档照原版。
- 验收：在坏版本里存过的旧档、或无小人世界里，文化图层每座城都有颜色；开关平滑国界颜色一致；鼠标悬停高亮、点击打开文化窗口照常。

## 原版王国窗口改的国名一个月后被改回(老问题)

- 原版王国窗口改名只写国家原名，模组每月按法理重起自动国名会把它覆盖(0.4.1 起就这样)。现在原版窗口改的名记成自定国名，和政体窗口里的国名输入框同一处，不再被改回；名字原样显示，不再自动加后缀。
- 打开窗口时输入框里填的是现名，不会被当成改名(和现名相同的一律不算)。
- 验收：原版王国窗口改名，过几个月、换君主、得法理后名字不变；只是打开王国窗口不改名的国家，国名照常随法理变化。
- 已经被改回的名字存档里没有留底，恢复不了。

## 全世界没人的存档补人口

- 在坏版本里读过又存过的档，所有城的背景人口都是 0、也没有实体小人；"空城等移民"的规矩下谁也长不起来。读档时若全世界的城都没有人(只在开着无小人模式时)，给每座城按保底补一户；只要还有一座城有人就不动。日志"全世界的城都没有人口……已给 N 座城各补一户"。
- 补的是农民、按城的物种和主流文化；原来的人口数救不回来，要慢慢长回去。
