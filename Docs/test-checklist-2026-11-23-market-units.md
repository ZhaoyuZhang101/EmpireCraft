# 验收清单 2026-11-23：市场缺木材、缺铜

## 有小人的世界：木材、铜、铁、煤不再常年缺一百

- 来由：群友反馈"整个游戏里面市场总是缺木和铜"。没开"无小人"法则(有小人)的世界里人口经济结算整个不跑：物资账从不翻页，铜、煤、硝石这些战略矿产不开采(只有模组的矿产系统出)，原版小人砍树挖矿交进仓库也不记账；商品市场读到的木材、铜、铁(按金属折)、煤产量都是零，造纸坊、窑场、铸铁坊、火药坊、船坞照样要木材，铸币局要铜，各市场就缺一百，科研变慢、工场减产。
- 现在：
  - 小人交货记作产出(`GoodsLedger.Gathered`/`Delivered`，接在 `Actor.giveInventoryResourcesToCity` 上；船是贸易不记；粮食不记，吃粮这头也不记账)；
  - 商品市场每年记各城的账之前，有小人的世界先按矿场开采这一年的战略矿产、翻账页(`GoodsLedger.UnitsYear`，`CommodityMarketSystem.Tick`)；
  - 市场读年账改用 `GoodsLedger.Year`：有上一年用上一年，头一年按已过的时间折算(同物资产需页)；一份账都没记过的城(剧本刚开局)，靠账本出产的原料(木材、铜、铁、煤、硝石……)先不记工场需求和储备，免得开局头一年各市场铁、煤、硝石缺一百。
- 验收：
  - 关"无小人"开随机地图玩到青铜时代以后、有了窑场/造纸坊/铸币局：外交界面市场页木材、铜不再常年 100%；有矿场的城物资账里有铜；Player.log 年度 `[市场] … 缺：` 不再列 timber、copper。
  - 剧本开局(纯净地图)：`[市场]` 第一轮结算不再一排 iron100%、coal100%、saltpeter100%。
  - 纯净地图(开着"无小人")的老局：市场数字与之前一样(那边本来就有整年账)。

## 军械不再常年缺三到七成

- 来由：Player.log 年度 `[市场]` 缺货里军械最常见(38 次)，莫卧儿、罗马、德意志、清、波兰常年缺三到七成；缺过一半火枪、火炮、步枪换装不了(`CommodityMarketSystem.CanEquip`)。账：每兵每年 0.02 份、打仗翻倍；产出几乎全靠手工每千人 0.85 份(跟价 0.75~1.5 倍)，铸铁坊、火药坊合计不到一成。临高存档(11-19)全图兵占人口 7.4%(莫卧儿 6%，朝鲜、齐 8% 多，清 17%，罗马 32%)，而以前兵过 4.3% 就缺、打仗过 2.1% 就缺。
- 现在：`Technology/Commodities.json` 军械手工每千人 0.85 → 1.5；打仗军需 ×2 → ×1.5(`CommodityMarketSystem.WarArmsFactor`)。平时兵占 7.5% 刚好够(跟价最多到 11%)，打仗紧一些但多半不过半；倾国动员的(罗马、清)照旧缺。
- 验收：近世以后(军械出现的时代)玩几十年，`[市场] … 缺：` 里 arms 不再年年三到七成、平时多为无；打大仗的市场缺一些但少过 50%；火枪、火炮换装不再长期卡住；军械便宜的市场会往外卖。
