# 外交界面方案(10-29 已做第一、二期，未进游戏验证)

## 要解决什么

现在国与国之间的关系散在十几处：原版好感、同盟，模组的朝贡岁币、封建附庸、帝国成员、殖民地、姻亲、兄弟之国、通好、保护约、扶立、停战年限、战争目标、关税同盟(市场经济)……每样各有各的入口，有的只有日志里看得到。外交界面把它们集中到一扇卷册宽窗里：一眼看清两国是什么关系、为什么好或坏，并能直接改。

## 窗口形制

照「卷册」设计语言做宽窗(左栏列表、右栏卡片、主指标组件)，不拿窄窗拉宽。

- **入口**：国家窗口加一个「外交」按钮；帝国页加一个「外交」权能，点地图上任一国家就打开，默认选中它。
- **左栏**：国家列表，可按天下、帝国、市场筛选，按名字搜索；当前国家置顶。
- **右栏分页**：

### 一、总览(选一国)

- 主指标：关系最好、最坏的几国，在打的仗，盟友数。
- 关系表：与每一国的态度(数值与档位)和关系类型标签(同盟、宗主/附庸、宗主/殖民地、朝贡/受贡、关税同盟、姻亲、兄弟之国、通好、保护约、扶立、停战剩余几年、交战中)。
- 点一行进入双边页。

### 二、双边(选两国)

- **好感构成**：原版好感各分项，加上模组的来源——同文化同天下、宗教、法理宣称与领土争议、历史恩怨(战争、篡位、背盟)、朝贡往来、通商与市场、姻亲。每项有数值和一句话说明。
- **现行条约**：每项的生效时间和剩余年限(停战、扶立二十年、保护约三十年、通好、关税同盟)。
- **往来大事年表**：两国之间的战争、和约、联姻、称臣、独立，从史书和日志里抽出来。
- **力量对比**：国力、兵力、海军、经济，宗主一系合计与否两种口径。

### 三、操作(按钮，上帝视角，不写"玩家")

每个按钮旁注明现在能不能做、为什么不能(直接复用 `WarGate.Forbidden`、`FeudalVassalService.CanBind`、`ColonySystem.Bound` 等判定给出的理由)：

- 结盟 / 解盟；宣战(先挑战争目标) / 议和；
- 称臣纳贡 / 解除朝贡；立为附庸 / 放还；
- 设为殖民地 / 放其独立；改派总督；特许公司收归国有；
- 拉入 / 逐出关税同盟；
- 联姻；订立通好、保护约；强制停战若干年；
- 好感加减(手动修正一项，标明是神力所为)。

### 四、市场(随市场经济一起做)

- 各共同市场：领衔大国、成员(殖民地、附庸、朝贡国、关税同盟)。
- 各物资的产量、需求、价格、缺口，进出口流向，奢侈品满足度。
- 关税同盟的加入、退出。

### 五、体系图

- 宗主—附庸—陪臣—殖民地—朝贡国的树；天下格局(各天下的共主与诸国)。

## 数据层

- 各类关系的判定统一成一个入口，界面和 AI 共用，免得两边说法不一。
