# 世家族众与入谱人数的显示

截图中的宗族详情为 427 名族众，其中 42 名在世族人逐人入谱；剩余 385 人是未逐人记谱的远支族众。帝国名录调用 `GentrySystem.Members`，详情分布原来却只统计 `LivingPeople`，两者均使用“族人”称呼，容易让玩家误以为进入详情后人口减少。荫户和部曲不是应加入族众的额外成员。

保留既有“入谱人物＋汇总族众”模型，不为汇总人数生成大量人物。调整如下：

- 帝国名录的列名明确为族众；宗族详情注明总族众、已入谱和未逐人入谱的分解。名录页和侧栏明确称为入谱族人，仍可查看已有个人生平。
- 总览分布使用同一族众口径。入谱人物按已有城市记录；未逐人记谱的族众按现有郡望人口模型计入郡望，并在界面说明这一规则，不宣称掌握其逐人居所。
- 城市按对象分组，避免不同城市因名称相同被合并。未知居所单列，超过前六座城市的成员保留在其余各城合计中。分布总数与总族众一致。
- 远支族人进入族谱只是从未逐人记谱变为逐人记谱，族众总量应保持不变；移除 `Revive` 中误减一人的逻辑。
- 继续使用现有卷册界面的段落、卡片、键值行和颜色。简体、繁体、英文同步。

`Tools/check_clan_population.ps1` 直接提取生产人口统计、城市分布及远支入谱方法，26 项检查覆盖截图的 427/42/385、未知居所、同名城市、实体与虚拟人物、毁城、去世人物、入谱下限、普通宗族、空谱仍有族众、入谱人口守恒及失败情况；另有 3 种本地化的键和格式检查。编译 0 错误、15 条既有警告。未进行游戏内视觉实测。
