# 新文化适配 测试清单(2026-11-06)

## 女真、青藏、班图、祖鲁、斯瓦希里的城市风格(用户："满洲和藏的城市风格也检查一下")
- 查到的问题：
  - 女真、青藏带"游牧"政治特性，城市平面图被判成游牧营地(蒙古包、不筑城墙、不修路、人口上限只有四成)。
  - 合并城池的贴图只有 11 个文化有自己的一套，其余一律借西欧石堡：女真、青藏、班图、祖鲁、斯瓦希里的城池画成欧洲城堡。
  - 原始制度线的文化(班图、祖鲁)没单列风格时按华夏城池画。
- 改法：
  - 城市风格：女真、青藏 → 华夏城池；斯瓦希里 → 阿拉伯；班图、祖鲁 → 林地营地(不筑城墙、只修土路)；原始线的其他自定义文化 → 林地。
  - 城池贴图：没有自己贴图的文化按城市风格借(华夏、阿拉伯、木栅营地……)，不再一律借西欧。
  - 游牧特性本身不动(游牧扩张、牧帐、劫掠照旧)，只改城画成什么样。
  - 已经定型的城不变(城市风格第一次定下就记在城上)；新开局、新建的城按新规则。
- 验收：女真、青藏国家新建的城是华夏式城池和平面图(有城墙、街道)，人口上限正常；斯瓦希里是穹顶城；班图、祖鲁是木栅营地。

## 剧本适配：非洲(含西非)、女真、青藏、印度制度(用户："非洲文化适配到剧本了嘛""还有政体""女真和青藏也一起适配吧""西非也找个文化适配一下"，西非选"萨赫勒用斯瓦希里、森林带用班图")
- 查到的问题：10 个时代的 inst.India 都是阿拉伯线节点，印度改走 Origins 线后对不上，孔雀、贵霜、莫卧儿和用印度文化的东南亚各国开局都是原始部落政体；班图、斯瓦希里、祖鲁、女真、青藏一个剧本都没用；赤道以南除海岸外没有城，补空小国按最近的城取了埃及、阿拉伯文化；只在原始部落圈里出现的文化拿不到科技(WorldMapScenario.SetupCultures 补上部落圈的文化)。
- 制度：印度各时代改用 Origins 线(王权、税制、近卫军官 → 原始封建制，中古加神权、封建化、种姓)；斯瓦希里走阿拉伯线(750 起阿拉伯政体)；班图 1140 起王权 → 原始封建制；祖鲁部落；青藏、女真走游牧线(女真照抄原来金、后金、清的游牧条目，八旗仍由剧本 banner 设定)。
- 新地区 11 个、新城 33 座：豪萨、加涅姆、约鲁巴、贝宁、刚果、安哥拉(恩东戈)、隆达、加丹加(卢巴)、大湖(基塔拉)、津巴布韦(莫诺莫塔帕)、纳塔尔(祖鲁)；僧祇海岸补桑给巴尔、帕泰、马林迪、索法拉；萨赫勒补奥达戈斯特、瓦拉塔、尼亚尼。城都按史实年份出现、废弃。
- 政权：750/800 加纳、加奥、加涅姆；1140 伊费、马蓬古布韦；1190 贝宁、基尔瓦；1258 马里(都尼亚尼)、加奥、大津巴布韦；1628/1638 博尔努、帕泰、奥约、贝宁、刚果、恩东戈、卢巴、隆达、布尼奥罗、布干达、卢旺达、穆塔帕、布图阿，罗安达、索法拉归葡属；上古非洲腹地是班图部落圈、萨赫勒是斯瓦希里部落。金、后金、清 → 女真；吐蕃、萨迦、藏巴、羌 → 青藏；卫藏、青海地区 → 青藏；辽东仍华夏，渤海仍华夏，和硕特仍游牧。
- 数据由 Tools/WorldMap 的源脚本生成(1140、1258、1638 从 1190、1628 底稿生成)，人口、宗教表重新生成；check_scenario 10 个时代 ok，check_historical_presets 1859 项全过。
- 已知：维多利亚湖北岸地形判成雨林无人区，布干达、布尼奥罗开局辖地偏小；萨赫勒、森林带借用斯瓦希里、班图的起名表；上古南非高原算班图(实际是科伊桑)；印度文化的东南亚各国也成原始封建制。
