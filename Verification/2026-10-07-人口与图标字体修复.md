# 人口、图标与铭牌字体修复验证

## 无小人模式

- 军团保存各来源城、阶层、文化、物种与理念；代表士兵本人另记来源，减员按比例扣除各组。
- 补员从现有背景人口扣除并记新来源。只剩代表士兵的军团仍能补员，普通单人单位不会被扩充。
- 退伍后按来源回乡；原城已不属于本国时归入当前驻地，保留各组身份。
- 旧存档没有军团来源记录，只能以现有士兵身份初始化，无法恢复过去已丢失的混合来源。
- 文化统计按实际人口组与军团来源计算，并保护仍有背景人口的少数文化；相同模板的多个原版 Culture 不重复汇总。
- 停用与重新开启时同步增长、经济与施工时钟，存档记录暂停状态；不补算停用年份。
- 饥荒使用实际进食与缺粮结果；年产量不再充作粮库现货。赈灾粮实际扣除后再计为吃到的粮食。
- 抽取兵源城市改为一次遍历的加权蓄水池抽样；年度结算不再随后集中执行全世界内存普查。迁移算法本轮未重写。

## 字体与 UI

- 下载作者仓库的敬峰中山王篆 JFZSKSealScript_V3.ttf，原文件与 OFL 许可放在 Assets/Fonts/JFZSKSealScript。
- 字库 3060 个 Unicode 映射，示例华夏、秦楚汉唐宋明清、洛阳、长安、帝国等字符均覆盖。
- 从文件直接创建 Unity Font，不修改系统字体。自动模式的中文名称优先选择内置篆书；用户仍能选择游戏字体和本机字体。
- 展示字体不支持完整铭牌文字时回退游戏字体，含中英文混合名字与未收录的空格。预览不用字体未收录的空格。
- 切换字体复用已创建的 Font，重置所有铭牌的材质、字符生成器与尺寸缓存。使用 Text 的默认 UI 材质跟随当前字体图集，不绑定旧字体材质。
- 字体窗口提供搜索、书体分组、分页；字体名称用游戏字体，字样单独预览，选中项用旧铜色。
- 已查看实际字体文件渲染的示例图；尚未在运行中的 WorldBox 验证 Unity 字体加载、反复切换与窗口最终布局。
